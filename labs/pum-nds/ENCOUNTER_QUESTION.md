# ¿QUÉ PUEDE HACER ESTO AHORA QUE HA CONOCIDO A AQUELLO?

This is the primary redefinition question for the PUM lab.

It applies across:
- OBJECTS
- CHARACTERS
- PLACES
- MEMORIES
- COLORS
- SOUNDS
- GESTURES
- DRAWINGS
- VOICE
- GIFTS
- RULES
- WORLDS
- MECHANICS
- AI OUTPUTS
- HUMAN INPUT

## Operational grammar

BEFORE ENCOUNTER:
A has current function/history.
B has current function/history.

ENCOUNTER:
A <-> B inside context C.

LIMINAL PHASE:
Inherited functions may become negotiable.

QUESTION:
What can A do now that it has met B?
What can B do now that it has met A?
What third possibility exists only because they met?

OUTPUT:
candidate relation / mechanic / transformation / memory / branch.

## Constraints
A good result must preserve:
- provenance;
- causal residue;
- reversibility;
- playability;
- human authority.

Do not reward novelty alone.
Reward:
USEFUL SURPRISE
× COHERENCE
× CONSEQUENCE
× HUMAN INTEREST.

## Game
The question should usually remain hidden behind play.
Players experience:
encounter -> consequence -> later realization.

## Family mode
Surface version:
"¿Qué puede hacer esto ahora que ha conocido a aquello?"

No technical vocabulary required.

## Serendipinator
Use this question as a trigger for bounded cross-entity candidate generation.

## Orchestrator
Before accepting a candidate, check:
- what existing systems it touches;
- what it replaces;
- what it risks duplicating;
- whether it improves circulation instead of adding another organ.
