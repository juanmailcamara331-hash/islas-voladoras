# ISL PUM · Priority Weights

1. UNREAL / SYSTEM PROVING VALUE — highest
   Can this experiment cheaply prove systems, save/state, ergonomics, input, causal mechanics, pipelines and tests that later reduce Unreal risk?

2. FUN / MECHANICAL VALUE — highest
   Is the game genuinely fun? Are turn-based combat, gesture/drawing and optional voice worth carrying into ISL?

3. COHERENCE / MANERA / NARRATIVE — supporting
   Does everything remain one coherent ISL organism rather than a pile of clever features?

4. VISUAL / MATERIAL QUALITY — supporting
   Beautiful, legible, close, visceral, square-screen friendly.

5. SERENDIPITY / DISCOVERY — supporting
   Does play create surprising candidate relationships without destroying clarity?

6. TRACE / EXPORT VALUE — supporting
   Can every important outcome be reconstructed, explained and handed to ISL systems?

7. PRODUCTION COST / TIME — constraint
   Prefer systems that can be tested cheaply now and scaled later.

No single lower-priority layer may sabotage priorities 1 or 2.
