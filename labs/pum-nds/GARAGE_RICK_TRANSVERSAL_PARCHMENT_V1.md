## 0. Why this exists
This is not another branch.
It is a transversal law that must stay available while every Garage process runs.

The Garage must never collapse a seed into one construct too early.

An input can simultaneously become:
- function
- object
- art
- mechanic
- campaign
- interface
- hologram interface
- music
- game mechanic
- character
- ritual
- research question
- scientific hypothesis
- marketing hook
- physical artifact
- joke
- scene
- system behavior
- abstract operator
- combinations of any of the above

The useful unit is often NOT a layer.
It is the RELATION BETWEEN LAYERS.

## 1. The dance law
LAYERS MUST DANCE WITH ALL OTHER LAYERS.

Not:
INPUT -> CATEGORY -> OUTPUT

But:
INPUT
-> MANY CANDIDATE FUNCTIONS
-> MANY LAYERS
-> CROSS-LAYER COUPLINGS
-> NEW COMBINATIONS
-> SMALL TESTS
-> HUMAN VERDICT
-> RETURN
-> RECOMBINATION

A mechanic can become music.
Music can generate a game mechanic.
An artistic object can carry a campaign.
A holographic interface can connect a mechanic to a joke, a character or an unrelated human phrase.
A bodily gesture can become a control, rhythm, scene, hook, artifact or research trace.

Never ask only:
"What is this?"

Also ask:
"What else can this become?"
"What can it connect?"
"What does this layer do to another layer?"
"What survives when they move together?"

Do not promote one interpretation into authority because it is neat.

Preserve:

- alternative readings
- rejected branches
- useful accidents
- layer crossings
- human corrections
- RETURN deltas
- recombination paths
