# ISL PUM · Blind Dialectical Passes v0.1
Status: PLAYER-READY BLOCKER

The sealed game must survive multiple passes without revealing content to the player-author.

## PASS 0 — BASELINE
Build a coherent complete playable loop.
No cleverness bonus.
Goal: it works.

## PASS 1 — CONTRADICTION
Independent reviewer/agent asks:
- what is generic?
- what is redundant?
- what is confusing?
- where does surprise destroy clarity?
- where does clarity destroy surprise?
Remove or mutate.

## PASS 2 — SYNTHESIS
Cross surviving systems:
PLAY + EXPRESS + REMEMBER + REDEFINE + ORCHESTRATE + TRANSFER.
Require interactions to earn their complexity.
Strengthen echoes/biographies only where they improve play.

## PASS 3 — ADVERSARIAL / BORING TEST
Try to make the game fail:
- repetitive
- predictable
- overexplained
- too many controls
- bad pacing
- dead inventory
- irrelevant meta systems
- visual clutter
- broken save/progression
Cut aggressively.

## PASS 4 — HUMAN SHADOW PASS
Only if needed before player build.

FUN
CLARITY
SURPRISE
MEMORY
COHERENCE
ERGONOMICS
NO SPOILERS
