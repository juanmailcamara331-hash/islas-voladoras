# SACARSE EL RABO · DOMINO PYRAMID MODEL V0.2

## Image
A pyramid of domino tiles.

Each tile may be simultaneously phrase, object, art, mechanic, interface, game, paper, body signal, sound, campaign, prototype, hypothesis, mistake, correction or memory.

Do not force one tile into one ontology too early.

## Operation
ONE ACT → MULTIPLE PROPAGATION PATHS → CROSS-LAYER COLLISIONS → CHEAP TESTS → HUMAN CORRECTION → DELAY → SURVIVORS

## What to preserve
Origin event; first interpretation; alternate interpretations; order of propagation; timing; branch deaths; accidental branches; corrections; later returns; cross-layer reuse; final survivors.

## Main research question
Does preserving propagation paths produce more useful delayed reuse than storing only final artifacts?

## Second research question
Does delayed semantic collapse preserve useful cross-layer affordances better than early classification?

## Rule
A failed local goal may still create useful value elsewhere. That secondary value must not be retroactively described as planned. Provenance stays honest.
