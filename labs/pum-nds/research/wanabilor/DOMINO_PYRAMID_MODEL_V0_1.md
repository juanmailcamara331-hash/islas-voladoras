# WANABILOR · DOMINO PYRAMID MODEL V0.1

## The image
Imagine a pyramid made of domino pieces.

Each piece can represent:
- art
- object
- mechanic
- game
- paper
- body signal
- phrase
- image
- sound
- campaign
- physical prototype
- hypothesis
- accident
- memory
- correction

A move does not have to "belong" to one category.

## Basic operation
TOUCH ONE PIECE
→ several possible cascades
→ some die immediately
→ some cross layers
→ some return later
→ one or two become useful

## Research translation
The important object is often:
**the path of propagation**.

Record:
- origin
- pieces touched
- order
- timing
- human correction
- accidental branches
- later reuse
- final survivors

## Why this differs from a simple flowchart
A flowchart assumes the path is known.
A domino pyramid allows:
- branching;
- interruption;
- reversals;
- collapse;
- reconstruction;
- delayed effects;
- surprising cross-layer paths.

## Testable question
Does preserving the propagation path produce more useful later reuse than saving only the final artifact?
