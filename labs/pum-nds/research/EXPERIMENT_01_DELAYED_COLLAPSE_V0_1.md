# GARAGE ZERO · EXPERIMENT 01 · DELAYED COLLAPSE V0.1

STATUS: TESTABLE · SMALL-N SELF-STUDY FIRST · NO CLAIM OF GENERALITY

## Question
Does preserving several possible functions/layers for one creative input produce more later-useful outcomes than assigning one function immediately?

## Input
Use 12 naturally occurring seeds across several days:
- phrase
- drawing
- object
- rhythm
- mistake
- image
- code fragment
- physical gesture

Do not manufacture all seeds in one sitting.

## Conditions

### A · EARLY CLASSIFICATION
For 6 seeds:
Within 60 seconds assign one primary class:
ART / OBJECT / MECHANIC / CAMPAIGN / INTERFACE / MUSIC / RESEARCH / OTHER.

Generate/test only inside that class.

### B · DELAYED COLLAPSE
For 6 seeds:
Keep 3–5 candidate layers alive.
Allow at least 2 cross-layer combinations.
Do not choose a winner until after cheap tests.

## For every seed record
- original trace
- provenance
- first interpretation
- candidate layers
- cross-layer edges
- artifacts produced
- corrections
- time spent
- immediate human rating
- delayed rating after 24h+
- reused later? yes/no
- reused in another project/layer? yes/no

## Primary measures
1. SURVIVOR RATE
How many outputs are still judged useful after delay?

2. CROSS-LAYER REUSE
How many become useful somewhere not predicted initially?

3. EFFORT
How much work was required?

4. OWNERSHIP
Does the result still feel authored/owned by the human?

5. SURPRISE WITH VALUE
Was it unexpected AND useful?

## Important
This is not a clinical study.
This is not proof of a universal creativity law.
It is a structured self-study / design experiment.

## Success criterion
The experiment is worth expanding only if delayed collapse yields a measurable benefit without unacceptable effort or loss of control.
