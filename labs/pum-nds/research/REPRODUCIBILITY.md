# ISL PUM · Reproducibility / Research Ops

1. Freeze every player build by commit + ROM hash.
2. Preserve original save before decoding.
3. Generate immutable run manifest.
4. Separate raw event data from derived interpretation.
5. Version every extractor and analysis rule.
6. Maintain a data dictionary.
7. Flag exploratory analyses as exploratory.
8. For confirmatory work, preregister hypotheses/analysis before data collection.
9. Preserve negative/null findings.
10. Never overwrite raw data.
11. Make synthetic/demo datasets for public tooling when private player data cannot be shared.
12. Keep ISL canon decisions separate from scientific conclusions.
