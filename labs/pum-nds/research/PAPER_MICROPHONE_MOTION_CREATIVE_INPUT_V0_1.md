# PAPER DRAFT B · MICROPHONE + MOTION AS CREATIVE INPUT V0.1

STATUS: WORKING PAPER · PHYSICAL-FIRST · NO EMOTION MIND-READING

## Working title
**Microphone, Motion and Rhythm as Explicit Creative Control in Embodied Human–AI Systems**

## Research question
Can voice acoustics, rhythm and simple body motion become useful creative controls without inferring hidden emotion or psychological truth?

## Observable input only
Microphone:
- loudness / energy
- pitch contour / range
- timing
- pause duration
- speech rate
- repeated syllables
- rhythm
- explicit transcript when available

Motion:
- foot taps
- left/right alternation
- finger gestures
- chain pulls
- deliberate body movement
- timing and sequence

## Candidate control model
VOICE + BODY + OBJECT + CONTEXT
→ explicit feature trace
→ candidate creative transformation
→ visible acknowledgement
→ human accept/reject
→ reversible mapping

## Example
"ajá" alone
≠ automatic emotional label.

"ajá" + repeated foot rhythm + explicit human confirmation
may become a learned command such as:
CONTINUE THIS DIRECTION.

The mapping is learned because the human assigns/accepts it, not because the system claims to decode inner emotion.

## Physical-first interface
Possible devices:
- microphone / old handset
- double-kick foot pedals
- pull-chain
- large KEEP/BACK controls
- mutation box
- thermal printer / e-ink / 3D output
- transparent/projection surface
- duck courier / physical return signal

## Why physical
Tangible and embodied interaction research treats physical objects, surfaces, spaces and whole-body action as legitimate HCI modalities.
The working hypothesis here is that these modalities may reduce interruptive chat turns and improve continuity of creative action.

## Candidate experiment
10-minute free jam:
- object
- voice
- feet
- one physical gesture
- no fixed semantic mapping initially

Phase 1:
record only observable features.

Phase 2:
user labels moments:
KEEP / BACK / CONTINUE / STRANGE / PARK.

Phase 3:
system proposes mappings from recurring patterns.

Phase 4:
human accepts/rejects each mapping.

## Measures
- false activation rate
- deliberate activation rate
- recognition latency
- mapping learnability
- subjective naturalness
- creative-flow interruption
- number of useful outputs
- number of rejected inferred meanings
- reversibility

## Important claim boundary
Acoustic features can be measured.
Meaning can be negotiated.
Emotion should not be treated as directly known.

This distinction is central to the paper.
