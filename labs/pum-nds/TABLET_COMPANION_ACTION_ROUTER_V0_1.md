# ISL PUM · Tablet Companion Action Router v0.1

Status: LAB ONLY · MOBILE-FIRST · SPOILER-SAFE

## Goal
While playing on R36/NDS, the tablet acts as a temporary expressive instrument, not a second game dashboard.

## Three actions only

### DRAW
Open a clean canvas.
Player may:
- sketch a ship / symbol / route / mark / nonsense;
- draw during a prompted or optional moment;
- finish with one TAP: SEND.

Record only observable features by default:
- stroke count
- duration
- occupied area
- direction / curvature summary
- revisions / erasures
- semantic label only if player explicitly names it

Optional AI interpretation is separate and reversible.
No psychological diagnosis.

### SPEAK
Push-to-talk.
Player can:
- shout;
- name;
- describe;
- command;
- joke;
- improvise.

Record:
- transcript when speech-to-text is invoked;
- timing / duration / rhythm features;
- source context;
- explicit intent where known.

No inference of mental illness, intelligence or true emotion.

### GENERATE
One visible action.
Behind it, Orchestrator routes to the cheapest appropriate path:

IMAGE
-> OpenArt / Gemini-class route

VIDEO
-> OpenArt / Gemini/Veo-class route
-> Runway only if a Runway-specific capability is justified

3D
-> Meshy API/MCP route

MUSIC
-> Suno-ready packet by default
-> direct automation only through verified official support

PROMPT PACK
-> ChatGPT / Claude / Context7-assisted technical grounding

Unsupported automation:
-> PREPARE
-> COPY
-> OPEN OFFICIAL APP/WEB
-> user presses Generate

## Context
DRAW / SPEAK / GENERATE may occur:
- between turns;
- during ship-combat preparation;
- after an encounter;
- at a safe checkpoint;
- when an Echo explicitly opens an expressive window.

Never interrupt reaction-critical combat unless explicitly designed.

## Translation chain
RAW HUMAN ACT
-> semantic event
-> Tempo / Biography / Echo
-> optional Redefinition
-> Playtrace
-> sealed game response
-> neutral export
-> Unreal / Creative / Research / Campaign pillar

## Generation safety/economy
Before any paid generation:
1. cheap text/structure pass;
2. use existing asset/reference if possible;
3. preview / low-cost generation;
4. Human/quality gate;
5. expensive refine only if justified.

## Campaign capture
Real-world photos/videos may be contributed from tablet.
Default state:
PRIVATE / MAKING-OF / PROVENANCE.

Public campaign use requires explicit approval.

## UI law
During ordinary play:
tablet is asleep / secondary.

When needed:
one card only:
DRAW
SPEAK
GENERATE

Then close and return to game.
