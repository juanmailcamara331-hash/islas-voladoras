# ISL PUM · Morning Coffee Dashboard

Status: LAB ONLY · NO CANON · HUMAN-GATED · SPOILER-SAFE

Purpose:
Give Juan a beautiful, low-friction morning view of the project without exposing sealed game content.

## Surface principle
CAFE FIRST.
THEN PROJECT.

The dashboard must fit in one calm screen.

## Five zones

### 1. HOY
What changed since last check:
- build status
- tests
- save integrity
- sync health
- research log status

No spoilers.

### 2. PUMS
Show only high-value candidate events:
- new system connection
- unexpected quality gain
- research-worthy observation
- Unreal-relevant result
- family/co-creation contribution

Never reveal sealed narrative content.

### 3. BOLITA
One moving indicator representing overall project circulation:
- healthy
- overloaded
- blocked
- ready to play

Do not reduce this to a fake single score.
It is a compact status summary with drill-down.

### 4. NEXT
Maximum 3 visible actions:
- one active
- one next
- one optional

Everything else hidden in backlog.

### 5. PAPER / UNREAL
Two quiet indicators:
- research evidence accumulated
- Unreal-transfer readiness

No prestige claims.
No "Nobel" or novelty claims without evidence.

## Tone
Calm.
Beautiful.
Sparse.
Deep black + phosphorescent green + restrained accent.
Large readable typography.
No dense dashboards.
No admin feeling.

## Morning ritual
Open dashboard.
Read in < 60 seconds.
Choose:
PLAY
PUM
PARK
RETURN

Then leave.
