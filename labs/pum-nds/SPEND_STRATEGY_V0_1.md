# ISL PUM · Spend Strategy v0.1

Status: LAB ONLY

Budget principle:
Spend to remove friction, improve quality, or create resilience.

## Worth paying now / already useful
- reliable microSD / backup storage
- USB-C microSD reader if tablet slot is inconvenient
- Meshy Pro
- Suno Pro
- OpenArt if one-click generation is useful
- Runway Standard only if Runway-specific capabilities are used
- cloud/API credits for verified official generation routes

## Wait
- Context7 paid plan unless free limits are exceeded or private-repo need appears
- blockchain deployment
- ad spend
- large Kickstarter spend
- mass physical production

## Never buy just to duplicate
A new subscription must add:
- unique capability
or
- lower friction
or
- materially better output
or
- backup resilience.
