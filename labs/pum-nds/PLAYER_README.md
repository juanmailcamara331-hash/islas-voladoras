# ISL PUM · PLAYER

Play naturally.

Buttons:
- D-PAD: move / navigate
- A: interact / confirm
- B: back / defend
- START: menu
- SELECT: PUM

Touch:
- draw / trace / manipulate when the game asks for it.

Microphone:
- optional. The game must always provide a non-microphone fallback.

Do not read development files if you want the blind run.
