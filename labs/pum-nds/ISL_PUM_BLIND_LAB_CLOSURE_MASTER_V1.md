## 11 · DOS RELOJES DEL RUNNER

### FAST LOOP · EXTERNAL · ~1 MIN CAPABLE

Puede despertar aproximadamente cada minuto si infraestructura externa lo permite.

Sólo:
SENSE
→ CLASSIFY
→ DEDUP
→ ENQUEUE
→ ONE SAFE ACTION OR NO-OP
→ VERIFY
→ STATUS
→ STOP.

Objetivo:
mover información y reducir latencia de colas.

No significa:
- una generación por minuto;
- un prompt creativo nuevo por minuto;
- gasto continuo;
- publicación;
- contacto;
- auto-canon.

### BASELINE SAFE CLOCK · 5 MIN

El contrato existente de 5 minutos sigue siendo el baseline seguro para:
- repo health;
- build status;
- queue dedup;
- provider status;
- handoff;
- verification.

El reloj de 1 minuto sólo reduce latencia cuando el coste es mecánico y acotado.

### SLOW CREATIVE LOOP

Consume una oportunidad preparada sólo cuando:
- existe contexto creativo real;
- no hay blocker superior;
- la perturbación aporta valor;
- coste está acotado;
- Human Gate existe.

Regla raíz:

FAST LOOP MOVES INFORMATION.
SLOW LOOP MOVES DECISIONS.
HUMAN MOVES AUTHORITY.

## 12 · ADAPTER LAYER

ENTITY TRUTH ≠ SERVICE-SPECIFIC INPUT.

## 13 · PROMPT / PROCESS POOL LAW

Prompts are artifacts, not authority.

A prompt may be generated from:
source entity
+ active context
+ protected grammar
+ reactants
+ target adapter
+ budget
+ constraints
+ test question.

The pool may hold many prepared prompts.
The runner may fire only jobs that are explicitly READY_LOW_RISK or HUMAN_APPROVED.

No autonomous prompt storm.

No recursive self-generation without a bounded experiment.

No provider result silently becomes a new source of truth.

## 16 · AUTOMATION TRIGGERS

Automation may be triggered by state, not by boredom.

Eligible triggers:
- build changed;
- provider task completed;
- queue stale;
- Human Gate waiting;
- device test due;
- meaningful contradiction;
- verified new evidence;
- provider capacity/reset approaching;
- Pizarra health changed materially;
- phase closure criteria reached.

Non-triggers:
- “one minute passed” by itself;
- desire to create more content;
- empty queue;
- provider credits merely exist.
