# GARAGE RICK · EMBODIED JAM TEST 01
STATUS: LAB ONLY · HUMAN-MEANING-FIRST · REVERSIBLE

## Why
The current physical-device grammar is not convincing enough yet.
Do not freeze object meanings by design.
Test the process as an improvised embodied jam and discover which gestures actually deserve to survive.

## Session
Duration: 8–12 minutes.
No normal screen unless needed for setup/recording.

Available ingredients:
- one meaningful physical object
- chain / cord / pull gesture
- voice / mouth / improvised rap
- body rhythm / feet / hands
- optional duck / delivery prop
- optional photo anchor (for example a photo of Gela, only if the user deliberately chooses it)
- PUM / GREEN / RED if physically available

## Raw loop
1. PICK
   Choose one object or image with real meaning.
2. SAY
   Speak or rap whatever comes, without explaining it first.
3. MOVE
   Use body, hands, feet, chain, rhythm.
4. PUM
   Capture one moment that felt worth keeping.
5. MUTATE
   Recombine one physical action + one spoken fragment + one object.
6. GREEN / RED
   GREEN = keep this state.
   RED = return to previous strong state.
7. RETURN
   Garage gives back one artifact in a non-screen form if possible.

## Example raw utterance
"This is a duck that comes from below, one, two, three, two..."
Raw phrases are traces, not truths. Preserve wording and timing before interpretation.

## Capture packet
Store only observable events:
- timestamp
- object/image id
- user-given meaning (optional)
- chain pulls: count / duration
- foot taps: left/right/timestamps
- hand/finger gesture id if explicitly mapped
- voice: transcript + timing + coarse acoustic features
- PUM / GREEN / RED events
- resulting artifact id
- human verdict after result

Never infer emotion, psychology, hidden meaning or subconscious intent.

## Abstraction pipeline
RAW ACT
→ FEATURE TRACE
→ HUMAN MEANING
→ CANDIDATE RELATION
→ ART / SCIENCE / MARKETING LENS
→ SMALL TEST
→ HUMAN VERDICT
→ KEEP / MUTATE / PARK / KILL

### ART lens
Ask:
- what formal relation appeared?
- rhythm, repetition, material, gesture, interruption, contrast?
- can the relation become image, sound, object, movement or scene?

### SCIENCE lens
Ask:
- what measurable relation appeared?
- timing, force, sequence, recurrence, coupling, hysteresis, phase, latency?
- can the relation be tested without claiming more than observed?

### MARKETING lens
Ask:
- what catches attention?
- what is memorable?
- what is repeatable?
- what could become a hook, ritual, campaign mechanic or interaction?

No lens becomes authority.

## What counts as success
Not "the chain worked" or "the duck worked".
Success means at least one of these emerges naturally:
- a gesture worth repeating
- a rhythm worth mapping
- an object relation worth preserving
- a voice fragment worth turning into a creative seed
- a physical output that feels better than a screen
- a device whose meaning becomes obvious through use

## What to kill
If an object needs explanation every time, park it.
If a ritual feels performative rather than useful, kill it.
If a device duplicates another device, merge or remove it.
If a gesture is fun once but not repeatable, keep as trace, not interface.

## First experiment hypothesis
Instead of assigning fixed meanings in advance:
OBJECT + BODY + VOICE + CHAIN
should be allowed to discover its own stable grammar through repeated human use.

The Garage should learn only after repeated explicit confirmation.
