# ISL PUM · QUALITY FLOOR & SYNTHESIS v1

Status: LAB ONLY · PLAYER-READY BLOCKER

## Principle
The game is only as good as the weakest player-facing layer.
No subsystem can compensate for broken controls, unreadable art, corrupt saves or boring play.

## Mechanical floor
Must have:
- understandable movement
- readable turn choices
- recovery loop
- progression without grind
- ship-combat lane before PLAYER_READY
- beginning/development/closure
- meaningful variation

## Ergonomic floor
- few semantic inputs
- progressive disclosure
- no finger gymnastics
- no critical reliance on uncertain emulator hotkeys
- single-screen-first
- square-safe framing
- feedback for press/hold/release/disabled states

## Visual floor
- production assets only after device-scale test
- silhouettes readable under effects
- effects confirm actions, never replace affordance
- no generic glow on every interactable
- consistent material/palette language

## Audio floor
- every important action has useful feedback
- technical PSG replaced before PLAYER_READY
- music supports pacing and state change
- silence remains available as a tool

## Save/recovery floor
- A/B generation model
- checksum/schema
- rollback
- corruption detection
- power-loss simulation
- device validation
- independent backup/export

## Multimodal floor
- raw observable features first
- consent before external upload
- classifier confidence
- uncertain signals never permanently punish/reward
- game works when models/services are offline

## Fun floor
Simulation may check:
termination
repetition
dead loops
control count
state coverage

Only humans can validate:
fun
surprise
comfort
emotional impact
desire to continue

## Production floor
Every production candidate carries:
source
version
provenance
dependencies
risk
status
human decision

## Transfer floor
Only approved:
function
data
observed evidence
move into Unreal.

## Campaign floor
No campaign system may distort the base game.
Optional collector loops must remain optional.
No pay-to-win.

## Synthesis law
Every mechanic must answer:
WHAT DOES IT DO?
WHY IS IT FUN?
WHAT DOES IT CONNECT TO?
WHAT DOES IT COST?
HOW DOES IT FAIL?
HOW DOES IT RECOVER?
HOW DOES IT TRANSFER?
WHO DECIDES IF IT STAYS?

## Promotion law
IF IT IS NOT TESTED, MEASURED OR HUMAN-VALIDATED,
IT IS NOT GREEN.
