# ISL PUM · Compact Creative Panel Spec

Purpose:
Test a smaller portable descendant of the existing ISL Creative OS / Portal Gun cockpit.

Targets:
- R36 Ultra: compact read-only / lightweight manipulation mode
- NDS: dual-screen compact mode
- tablet: full touch mode
- future Unreal: immersive debug/creative cockpit

Design:
No spreadsheet.
No tiny sliders.
No dense HUD.

Surface:
- one central field/orb
- 3-5 large contextual controls
- visible current pressure / branch
- hidden detail behind long-press / shoulder modifier
- branch simulation shown as simple electrical paths
- weights shown visually, not as text-heavy dashboards

Core operations:
PIM
PAM
PUM
PARK
RETURN

Optional compact layers:
- CURRENT
- BRANCH
- WEIGHTS
- TRACE
- SAFE HARBOR

Branch visualization:
Use small electrical / living lines:
CURRENT STATE
-> candidate A
-> candidate B
-> candidate C

Each branch displays only:
- expected function
- confidence/pressure
- reversibility
- cost
- evidence source count

Never auto-commit from panel.
Simulation only until Human Gate.

Portable panel should preserve the existing Creative OS principle:
ENGINEER INSIDE · STREET/GRANDMA OUTSIDE.
