# GARAGE RICK · CAMPAIGN MONEY MACHINE V0.1

STATUS: LAB ONLY · HUMAN-GATED · CROSS-PROJECT METHODOLOGY ONLY

## Mission
Turn a campaign brief plus real performance data into a professional multi-channel campaign plan, creative production queue, budget allocation proposal and measurable RETURN loop.

This is a Garage Zero machine. It may serve ISL, Kickstarter launches or other projects, but it does not absorb project identity, canon or content authority.

## User surface
The operator should be able to set, with a compact physical/old-machine style control panel:

- objective: awareness / leads / prelaunch / Kickstarter / sales / retention
- total budget
- time window
- channels enabled
- max spend per channel
- target markets
- audience hypotheses
- creative tone
- visual intensity
- copy density
- novelty / familiarity
- risk tolerance
- evidence weight
- automation level
- Human Gate strictness

Each channel is treated as a source + action adapter:
- Kickstarter
- Instagram
- Meta Ads
- Google Ads
- YouTube
- TikTok
- SEO / Search
- Email
- organic social
- external research / benchmark sources

## Data layer
The engine can consume:
- first-party campaign history
- analytics and conversion data
- ad-platform statistics
- SEO/search data
- social performance
- creative metadata
- spend / CPA / CTR / CVR / ROAS / retention where applicable
- historical benchmark datasets from 2010 onward when provenance and comparability are known

Historical data never becomes authority by age or volume alone. Every datum carries provenance, date range, market, channel, objective and confidence.

## Campaign graph
A campaign is not one ad. It is a graph of:
- objective
- audience
- promise
- proof
- creative
- channel
- spend
- landing destination
- conversion event
- metric
- learning

The engine optimizes links between them instead of flattening everything into one score.

## Combination engine
Example operator request:
"Kickstarter + Instagram + Google Search, 2,000 EUR, dark-fantasy tone, 60% evidence / 40% exploration."

The machine proposes:
- budget split
- channel role
- asset set
- copy variants
- keyword/search clusters
- posting/ad cadence
- landing/Kickstarter message alignment
- measurement plan
- stop/scale conditions

It may offer multiple portfolios such as:
- conservative
- balanced
- exploratory

It must never silently spend or publish.

## Creative production
For each approved campaign portfolio the machine can create a queue for:
- static images
- short video
- vertical video
- hooks
- headlines
- body copy
- CTAs
- Kickstarter page blocks
- social captions
- SEO titles/descriptions
- keyword/content briefs
- landing-page variants

Production engines are adapters. The machine chooses and routes; project authority remains outside the machine.

## Budget allocator
The allocator must support:
- fixed minimum/maximum spend by channel
- exploration reserve
- proven-channel reserve
- cost caps
- learning thresholds
- pause thresholds
- scale thresholds

No automatic increase in spend beyond user-approved limits.

## RETURN loop
Every campaign run must return:
RESULT
→ HUMAN CORRECTION
→ DELTA
→ SMALL ADJUSTMENT

The learning record stores:
- what was tried
- where
- spend
- audience
- creative fingerprint
- outcome
- confidence
- human verdict
- next permitted change

## Bots
Bots may:
- collect metrics
- deduplicate evidence
- detect anomalies
- generate candidate portfolios
- prepare creative variants
- prepare SEO/keyword clusters
- stage campaigns
- compare results
- surface likely next actions

Bots may not:
- invent performance data
- hide spend
- publish without permission
- escalate budgets above limits
- rewrite project identity
- promote a hypothesis to truth without evidence

## External adapters
Target adapter families:
- Google Ads
- Meta / Instagram
- TikTok
- YouTube
- Kickstarter export / campaign prep
- analytics
- SEO providers
- Supermetrics-like aggregation
- n8n orchestration
- image/video generation providers
- email/CRM

All external actions pass through preflight + permission scope + Human Gate.

## Preflight
Before any paid/published action:
ACCOUNT
→ CONNECTION
→ PERMISSIONS
→ BUDGET
→ COST ESTIMATE
→ TARGET
→ CREATIVE
→ TRACKING
→ POLICY
→ HUMAN APPROVAL
→ EXECUTE

## Success
V0.1 is successful when one brief can produce:
1. three channel portfolio candidates,
2. a budget split respecting limits,
3. a creative production queue,
4. a measurement contract,
5. a RETURN packet format,
6. zero external publishing or spend without explicit approval.
