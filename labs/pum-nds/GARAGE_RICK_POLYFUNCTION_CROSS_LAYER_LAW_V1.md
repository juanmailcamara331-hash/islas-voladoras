## Regla raíz
NO REDUCIR UNA ENTRADA A UN SOLO CONSTRUCTO.

Una misma semilla, gesto, objeto, frase, sonido, error, imagen, ritmo, accidente o acción puede producir varias funciones válidas a la vez y atravesar varias capas sin perder provenance.

## Forma correcta
INPUT
→ MULTIPLE CANDIDATE FUNCTIONS
→ MULTIPLE LAYERS
→ CROSS-LAYER COMBINATIONS
→ SMALL TESTS
→ HUMAN VERDICT
→ KEEP / MUTATE / PARK / KILL
→ RECOMBINE AGAIN

## Regla anti-cajitas
El Garage no debe preguntar primero:
"¿Qué es esto?"

Debe preguntar:
"¿Qué funciones puede producir esto?"
"¿En qué capas puede vivir?"
"¿Qué combinaciones nuevas aparecen entre esas capas?"
"¿Qué sobrevive al uso humano?"

## Preservación
No colapsar pronto una entrada en:
- una categoría
- una identidad
- una única finalidad
- una interpretación dominante

Conservar:
- provenance
- funciones paralelas
- bifurcaciones
- relaciones entre capas
- accidentes útiles
- ramas rechazadas recuperables

## Serendipia
La serendipia útil puede aparecer no sólo dentro de una capa sino ENTRE capas.

Ejemplo:
ritmo corporal
→ patrón musical
→ control de juego
→ gesto de interfaz
→ hook publicitario
→ objeto físico

La conexión entre capas puede ser más valiosa que cualquiera de las capas por separado.

## Human Gate
La IA puede:
- proponer funciones
- descubrir cruces
- recombinar capas
- preparar pruebas

La IA no puede:
- declarar la función definitiva
- convertir una hipótesis en canon
- borrar ramas por simplificación
- imponer una lectura única

La persona decide qué combinación merece sobrevivir.

## Ley corta
UNA ENTRADA PUEDE SER MUCHAS COSAS A LA VEZ.

NO CLASIFICAR DEMASIADO PRONTO.
NO COLAPSAR.
CRUZAR.
PROBAR.
CONSERVAR LO QUE VIVE.
