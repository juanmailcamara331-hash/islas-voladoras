# Laboratorio web de Islas Voladoras

Panel local/estático para probar rápidamente la topología ZG sin editar el proyecto Godot.

## Parámetros

- `seed`: semilla del mundo.
- `route_width`: ancho visual/experimental del corredor.
- `level_step`: desnivel por tramo.
- `overlap`: solape de los conectores.

La interfaz dibuja planta y perfil, permite copiar/descargar JSON y queda preparada como superficie de control para futuras integraciones con el export Web de Godot.

## Importante

El laboratorio es una capa de experimentación y no sustituye el checkpoint ZG. Los cambios de esta carpeta no deben alterar el sistema validado de controles ni la geometría fuente hasta que una variante haya sido validada.
