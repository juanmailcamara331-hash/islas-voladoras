# ABSTRACT · CREATIVE ORGANISM SCORING + PROMPT ROUTER v0.1

Status: EXPORTABLE METHOD · DE-IDENTIFIED · PROJECT-AGNOSTIC

Purpose: reuse a living-system model for artistic, scientific, philosophical or spiritual projects without importing any source project's identity, lore, assets or decisions.

## Entity model
Each active entity can declare:
- PURPOSE
- HEART: why it matters to humans
- SPINE: authority / constraints
- ORGANS: functional subsystems
- SKIN: presentation / aesthetics
- NERVOUS SYSTEM: triggers / feedback
- MEMORY: provenance / history
- IMMUNE SYSTEM: safety / regression guards
- METABOLISM: inputs → transformation → outputs

## Health grades
0–100 only when evidence exists:
C clarity
A agency/actionability
F feel/response
D desire/retention
R robustness

Q_FLOOR = min(C,A,F,D,R)
Q_MED = median(C,A,F,D,R)
Q_STABLE = median(last N Q_MED) - MAD(last N Q_MED)

Always attach sample size, evidence source, date, uncertainty and a human note.
Use qualitative bands when evidence is sparse.

## Prompt router
For major creative work:
RECOVER → PREFLIGHT → relevant organ health → 2–4 locks → one risk → one unresolved question → weighted prompt → falsifiers → human gate → output → read → KEEP/MUTATE/PARK/KILL → return home.

Do not dump the full organism into every prompt.

## Visual body interface
Possible internal representation:
- colors = state;
- size = structural weight;
- line thickness = dependency strength;
- pulse = recent activity;
- heatmap = evidence/risk/readiness;
- floating cards = source, gate, next test;
- word mosaics = themes/feedback only with provenance.

Never let internal dashboards dictate public/player UI.

## Transfer rule
Export structure, not identity.
Never export private data, project-specific lore, branding, assets, decisions or user profiles.
