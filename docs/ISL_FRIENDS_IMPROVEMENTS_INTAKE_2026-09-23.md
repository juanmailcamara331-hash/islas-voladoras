## 3. REPLAY STRUCTURE · THREE-LAYER ESCALATION
Human hypothesis:
replayability should reveal deeper layers rather than simply restart the same game.

### RUN 1 · DISCOVERY / CREW ASSEMBLY
- player begins with a clear objective such as searching for a chest/relic;
- during the journey, finds/recruits future core crew members;
- easter eggs remain hidden with no explicit hints;
- world feels relatively grounded compared with later layers;
- completion should imply that the story/world is not exhausted.

### RUN 2 · PORTAL / WHITE ROOM / EXPANSION
- completion unlocks a second-layer altered run;
- a portal can lead to an abstract white-room-like space;
- this layer may unlock new abilities/rules;
- player now has access to several major characters found during Run 1;
- world is recognizably the same but modified;
- more explicit traces/hints can point toward hidden material.

### RUN 3 · FULL CREW / PRISM ESCALATION
- player must rediscover/reassemble the principal characters;
- easter eggs and hidden content become much more extreme;
- higher-concept / PRISM / “barbarity” escalation allowed;
- full-crew traversal can recontextualize earlier spaces;
- late-run power escalation may become intentionally excessive, but still ISL and not franchise imitation.

Status:
VERY STRONG SYSTEM HYPOTHESIS.
Needs cheap structural test before CANON because it affects progression, save architecture, narrative and scope.

Core question:
Does each replay feel like the same world revealing another truth, rather than NG+ adding arbitrary bonuses?
