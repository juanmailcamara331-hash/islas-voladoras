# ISL — RPG COMMAND CENTER SPEC v0.29

## IDEA
Convertir la entrada del Centro de Mandos en una capa RPG diegética que represente el proyecto y la expedición real sin convertir producción en un juego falso.

## PANTALLA DE INICIO
**PERFIL DEL CARTÓGRAFO**
- Nombre / alias
- Rango
- Nivel de Expedición
- Región actual
- Último checkpoint
- Estado PRE actual
- Energía creativa / racha (solo visual, no gate real)
- Accesos rápidos: Inventario / Misiones / Música / Mapa / Centro técnico

## INVENTARIO
Slots visuales tipo RPG:
- EQUIPADO
- RELIQUIAS
- MUESTRAS DE CIELO
- SEÑALES
- ARCHIVO NEGRO
- MÚSICA
- DOCUMENTOS
- OBJETOS DE USO PERDIDO

Cada item:
- nombre ISL
- foto
- procedencia real
- fecha
- categoría
- rareza diegética
- función física
- función ficticia
- estado real: EXPERIMENTO / PROVISIONAL / CANON / REJECTED-LEARNED
- notas
- vínculo a foto/documento

## REGLA CRÍTICA
La capa RPG nunca sustituye la verdad de producción.
Ejemplo:
“Rareza: ÉPICA” puede ser estética.
“Estado: CANON” sólo cambia mediante gates reales.

## HOME FLOW
Abrir app
→ ficha de Cartógrafo
→ botín reciente + misión activa
→ botón “Entrar al Centro de Mandos”
→ Command Center técnico existente
