# ISL — PC-PRE60 FEEDBACK SYNTHESIS ENGINE v0.20
Fecha: 2026-09-18
Estado: PREPARADO / ESPERA DATOS HUMANOS

## Entrada
- respuestas de Jotform "ISL · Lo que se quedó contigo";
- observaciones del facilitador;
- JSON local de sesión sólo con consentimiento;
- notas libres del tester.

## Salida
Una síntesis corta y accionable, no un informe kilométrico.

## MATRIZ C1–C6
C1 compañero recordado
C2 objetivo previo entendido
C3 fallo entendido
C4 prioridad recordada
C5 pérdida inferida
C6 siguiente intención

## CLASIFICACIÓN
GREEN = 5–6
AMBER = 3–4
RED = 0–2

## EJES SECUNDARIOS
- tono propio;
- humor funciona / rompe;
- poesía funciona / se nota escrita;
- oscuridad ganada / brusca;
- sorpresa;
- deseo de continuar;
- claridad de "el cielo" como sistema;
- recuerdo espontáneo de una frase/imagen.

## REGLA DE SÍNTESIS
Cada hallazgo debe terminar en una de:
KEEP
TUNE
CUT
PROTOTYPE
DEFER

## FORMATO DE SALIDA
### 1. Señal principal
1–3 frases.

### 2. Qué sobrevivió
máx. 5 puntos.

### 3. Qué confundió
máx. 5 puntos.

### 4. Frases / beats
KEEP / TUNE / CUT.

### 5. Gate
GREEN / AMBER / RED.

### 6. Acción siguiente
una sola acción prioritaria.

## ANTI-SESGO
- no corregir una escena por una preferencia aislada;
- separar comprensión de gusto;
- separar recuerdo espontáneo de reconocimiento al verlo;
- no convertir "me gustó" en evidencia de claridad;
- no convertir "no me gustó" en evidencia de fallo sistémico;
- registrar contradicciones entre testers.

## SI HAY 1 TESTER
Resultado = señal temprana, no conclusión.

## SI HAY 3–5 TESTERS
Buscar patrones repetidos y discrepancias.

## SI HAY 6+
Se puede empezar a comparar cohortes básicas sin sobreinterpretar.

## PC-PRE60 PASS
No existe por volumen.
Existe cuando hay una hipótesis concreta de mejora respaldada por observación real y lista para PC-PRE70.
