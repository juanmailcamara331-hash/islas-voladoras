# ISL — PRE-GAME METHODOLOGY ADDENDUM v0.19
Fecha: 2026-09-18
Estado: ACTIVO

## PRINCIPIO
Todo lo anterior a Velaria forma parte del juego y debe pasar la misma metodología que una mecánica o región.

## NUEVOS DOMINIOS OBLIGATORIOS DEL REVISOR
- BRAND / logo / firma sonora;
- FIRST BOOT / accesibilidad;
- TITLE / welcome screen;
- OPTIONS / input / audio / subtítulos;
- PROLOGUE / onboarding;
- SEPARATION / giro narrativo;
- LANGUAGE / tono;
- FIRST-30-MINUTES / ritmo;
- HANDOFF_TO_VELARIA.

## REGLA DE REFERENCIAS
Una referencia nunca entra por gusto.
Para cada referencia registrar:
1. función que estudiamos;
2. qué hace realmente jugando;
3. qué problema resuelve;
4. qué coste introduce;
5. qué NO queremos copiar;
6. experimento ISL equivalente.

## MATRIZ DE COMPARACIÓN
Toda intro candidata se compara por:
- seconds_to_control;
- minutes_to_first_relationship;
- minutes_to_core_mechanic;
- minutes_to_first_surprise;
- cinematic_to_play_ratio;
- explicit_tutorial_load;
- menu_friction;
- accessibility_before_cinematic;
- first_session_skip/replay behavior;
- emotional_memory_after_30m;
- handoff_strength_to_first_region.

## TONO
Para referencias autorales/literarias:
- abstraer mecanismos, no reproducir voz;
- convertir rasgos en reglas observables de escritura;
- probar el tono en diálogos/carteles/descripciones cortas;
- CQC debe separar HUMOR, EMOCIÓN, CLARIDAD y FATIGA.
