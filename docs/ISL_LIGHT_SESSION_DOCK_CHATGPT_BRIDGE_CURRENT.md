# ISL · LIGHT SESSION DOCK / CHATGPT BRIDGE · CURRENT
Fecha: 2026-09-23
Estado: ACTIVE DIRECTION · PRIVATE CONTROL · ADDITIVE · NO NEW ORGAN

## PURPOSE
Allow low-energy / tablet / Play-like ISL sessions without losing continuity or forcing full Command Center use.

The dock is a lightweight front door into existing systems.

## MODES
1. QUICK NOTE
2. VOICE NOTE
3. IDEA → INTAKE
4. PREPARE CHATGPT HANDOFF
5. COPY HANDOFF
6. OPEN CHATGPT
7. SESSION END → SAVE SUMMARY

## VOICE
Preferred low-friction flow:
record locally with browser MediaRecorder;
optional browser speech recognition when available;
always preserve manual text fallback.

Voice capture may produce:
- raw audio;
- transcript;
- 1-line intent;
- tags;
- proposed destination.

No voice note mutates CANON.

## HANDOFF PACKET
Generate a compact prompt containing only:
- project = ISL;
- PRIMARY;
- current checkpoint/pointer;
- active subject;
- 2–4 relevant locks;
- one risk;
- one unresolved question;
- requested action;
- RETURN HOME rule.

Do not dump the entire methodology into every handoff.

## CHATGPT CONNECTION
Phase 1 / safest:
COPY PROMPT + OPEN CHATGPT.
No credentials in frontend.

Phase 2 / optional:
server-side adapter/API endpoint that can submit structured handoff to an approved AI endpoint.
Never expose API keys in HTML/JS.

Direct ChatGPT-account conversation insertion is not assumed available from a static page.

## SESSION END
One button should produce:
- what happened;
- decisions;
- evidence/assets created;
- open gates;
- next best action;
- ready-to-copy next-session prompt.

Optional:
save locally first;
persist to project only after explicit user action.

## COMMAND CENTER INTEGRATION
Class = SYSTEM / CREATE depending action.
Use existing action router.
No new authority.
No automatic CANON.

## TABLET / LOW-ENERGY DESIGN
One screen.
Large touch targets.
Dark/light accessible contrast.
Voice button prominent.
Maximum 3 primary actions visible.
Technical details collapsed.
Offline/local fallback when possible.

Suggested top row:
[ HABLAR ] [ ESCRIBIR ] [ CONTINUAR ]

Suggested bottom actions:
[ GUARDAR NOTA ]
[ PREPARAR CHATGPT ]
[ COPIAR PROMPT ]

## ORGANISM LINK
The dock may show a tiny organism status strip:
HEART · SPINE · ACTIVE ORGAN · OPEN GATE
using semantic colors only as secondary signals.

No dashboard overload.

## SAFETY / PRIVACY
- private surface;
- no secrets/API keys in client;
- explicit consent before uploading voice;
- local-first where possible;
- do not auto-send personal anecdotes to external tools;
- human trace gates remain active.

## PRINCIPLE
LIGHT SESSION != LIGHT MEMORY.
The interface becomes simpler while the underlying continuity remains strong.
