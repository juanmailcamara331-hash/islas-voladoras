# ISL · MARKETING / SEO / GTM MASTER · CURRENT
Fecha: 2026-09-22

## PRINCIPIO
NO HACER MARKETING DE HUMO.
Convertir el propio proceso creativo de ISL en descubrimiento, comunidad y memoria.

## POSICIONAMIENTO
Promesa:
aventura de islas voladoras + tripulación/hogar + decisiones que dejan huella + mundo extraño, humano y contemplativo.

No vender "IA".
La IA es infraestructura de producción, no identidad del juego.

## 5 MOTORES
1. SEARCH / SEO
2. STORE / STEAM
3. CONTENT / MAKING-OF
4. COMMUNITY / PARTICIPATION
5. PRESS / CREATOR OUTREACH

## SEO
Foundation:
- landing indexable y rápida;
- títulos/descriptions humanos;
- canonical;
- sitemap;
- robots;
- OpenGraph;
- structured data sólo donde corresponda;
- VideoObject para piezas públicas con página propia;
- SoftwareApplication si encaja legal/técnicamente;
- Search Console;
- páginas temáticas que respondan intención real, no keyword stuffing.

Clusters:
- Islas Voladoras / ISL
- juego de islas voladoras
- indie RPG / exploration / floating islands
- desarrollo abierto / making of videojuego
- arte y diseño de criaturas/reliquias
- música original del juego
- diario de desarrollo

Regla:
people-first. Cada página debe existir porque merece ser vista aunque Google no existiera.

## STEAM
Gate para publicar Coming Soon:
- identidad visual suficientemente estable;
- core feature set entendible;
- gameplay real mostrable;
- capsule/trailer no engañosos;
- rights/provenance cerrados.

Una vez gateado:
- Coming Soon cuanto antes;
- wishlist CTA consistente;
- tags precisas;
- idiomas definidos;
- announcements ligados a hitos reales;
- estudiar wishlist reporting;
- usar traffic breakdown para atribución.

Wishlists son valiosas como canal de notificación e interés, no tratarlas como un "hack algorítmico".

## CONTENT ENGINE
Cada hito puede generar, sin forzar:
- 1 pieza HERO;
- 2–4 derivados;
- 1 making-of;
- 1 micro-post;
- 1 reusable asset;
- 1 archive/provenance entry.

Ejemplos:
Ancla física → supplier journey → sample → CQC → relic lore → short video.
Atardecer huella → postcard → ambient audio → scene seed → making-of.
Velaria test → gameplay clip → design insight → short devlog.

## CUARTA PARED / EASTER EGG
Piezas promocionales pueden volver al juego como:
- posters;
- boards;
- postcards;
- fake archive;
- crew notes;
- radio/audio;
- collectible relics.

Marketing no debe ser una capa ajena: debe dejar fósiles en el mundo.

## COMMUNITY
Fases:
PRIVATE → FRIENDS/FAMILY → SMALL CLOSED CREW → OPEN DEVLOG → PUBLIC COMMUNITY.

No abrir Discord grande antes de que haya ritmo y alguien pueda cuidarlo.

## PRESS / CREATORS
Usar el directorio existente.

fit > relationship > timing > language/region > reach.
No spam.
Cada contacto recibe un ángulo concreto y un asset relevante.

## CALENDARIO POR GATES

### FASE 0 · AHORA → 2 semanas
No campaña.
- legal/provenance audit;
- PRIMARY/HUMAN_DEVICE_GREEN;
- marketing asset registry;
- SEO technical baseline;
- define 3 content pillars;
- capture making-of automatically.

### FASE 1 · semanas 3–6
Quiet audience building.
- landing pública mínima si art/core stable;
- 1 excellent dev artifact/week;
- 2–3 short derivatives/week;
- start Search Console;
- build mailing/waitlist only if useful;
- small creator/friends tests.

### FASE 2 · semanas 7–12
Store readiness.
- Steam Coming Soon only after gate;
- gameplay trailer;
- capsule tests;
- tags/languages;
- 4–6 week content bank;
- first targeted press/creator contacts.

### FASE 3 · pre-demo / festival
- demo quality gate;
- outreach wave;
- trailer cutdowns;
- creator keys;
- scheduled devlogs;
- community feedback loop;
- festival calendar.

### FASE 4 · launch runway
T-8 weeks: page/assets locked enough, press list refreshed.
T-6: trailer/announcement beat.
T-4: demo/update beat.
T-2: creator/press follow-up, FAQ/support.
T-1: launch logistics, no giant feature churn.
Launch: release + monitoring + support.
T+1–4: patches, community, update content, learn.

## CADENCE
Monday: product truth → what is actually worth showing?
Wednesday: one build/making-of extraction.
Friday: one public artifact only if quality threshold passes.
Monthly: SEO/store/content audit.
Quarterly: positioning/market/channel review.

## AUTOMATION
Marketing never invents activity.
Trigger only from:
- meaningful asset;
- validated mechanic;
- human trace;
- sample/prototype;
- build milestone;
- music piece;
- public-ready scene.

Then:
EVENT → MARKETING ROUTER → RIGHTS CHECK → FORMAT RANDOMIZER → DISTRIBUTION → METRICS → LEARNING → PRIMARY.

## STOP RULE
If marketing begins steering unfinished design for vanity metrics, stop.
Product evidence outranks content performance.
