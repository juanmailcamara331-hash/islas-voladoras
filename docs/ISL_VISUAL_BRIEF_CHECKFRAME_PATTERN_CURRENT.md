# ISL_VISUAL_BRIEF_CHECKFRAME_PATTERN_CURRENT

Fecha: 2026-09-22
Estado: ACTIVE · ISL ONLY · SOURCE_OF_TRUTH para briefs/rumbo visual
Origen funcional: dossier visual ISL de 5 páginas + rumbo v0.89.
Regla: abstraer función/estructura; no copiar mecánicamente un layout.

## PROPÓSITO
Convertir información compleja de ISL en piezas que apetezca mirar, imprimir, enseñar y corregir.

La superficie debe responder en segundos:
1. ¿Qué es?
2. ¿Por qué importa?
3. ¿Qué está hecho?
4. ¿Qué toca ahora?
5. ¿Qué viene después?
6. ¿Dónde puedo mirar/jugar/decidir?

## GRAMÁTICA VISUAL MAGISTRAL
### 1. HERO / PROMESA
- una imagen ISL fuerte;
- un titular grande;
- una frase humana;
- 1 promesa;
- máximo 3 accesos/pilares.

### 2. QUÉ ES
- premisa;
- experiencia;
- 3–4 pilares;
- tono/alma;
- promesa al humano.

### 3. QUÉ SE PUEDE TOCAR
- prototipo / escena / objeto;
- qué valida;
- una imagen;
- una acción;
- progreso visible.

### 4. CÓMO TRABAJAMOS
- bucle visual corto;
- calidad/criterio;
- pocas reglas cognitivas;
- lanes paralelas subordinadas;
- herramientas como soporte, no protagonistas.

### 5. HACIA DÓNDE VA
- convergencia;
- 4–6 líneas de crecimiento;
- hitos;
- una oportunidad/promesa futura;
- cierre humano.

## CHECKFRAME UNIVERSAL
Toda superficie de rumbo importante puede usar:

[✓] HECHO
[ ] AHORA
[ ] DESPUÉS

Reglas:
- HECHO = evidencia o artefacto real existente.
- AHORA = máximo 1–4 cosas.
- DESPUÉS = sólo lo suficientemente cerca para orientar.
- no llenar el marco con backlog.
- cada check debe poder verificarse.
- si algo deja de importar: PARK/KILL, no arrastrarlo por inercia.

## LENGUAJE
Preferir:
- verbo + objeto;
- frases cortas;
- lenguaje humano;
- una idea por bloque;
- títulos memorables;
- notas marginales cuando aporten alma.

Evitar en superficie humana:
- IDs;
- nombres internos de pipeline;
- estados de máquina;
- provenance extensa;
- fórmulas salvo que ayuden a decidir;
- párrafos explicando lo que una imagen ya cuenta.

Regla:
CONTENIDO PRIMERO · SISTEMA DETRÁS.

## IMAGEN
La imagen no decora.
Debe cumplir una función:
- situar;
- prometer;
- explicar escala;
- mostrar consecuencia;
- comparar;
- emocionar;
- recordar.

Preferir 1 imagen dominante sobre 6 miniaturas sin jerarquía.

## ESTRUCTURA DE BRIEF CORTO
1. PROMESA
2. IMAGEN / REFERENCIA
3. OBJETIVO
4. 3–5 PILARES
5. HACER
6. NO HACER
7. [✓] HECHO / [ ] AHORA / [ ] DESPUÉS
8. CRITERIO DE SALIDA
9. LINKS / ARCHIVOS AL PIE

## ESTRUCTURA DE DOSSIER 5 PÁGINAS
P1 · portada/promesa.
P2 · visión.
P3 · piezas/prototipos.
P4 · método/calidad.
P5 · rumbo/hitos.

No es obligatorio usar cinco páginas.
La regla funcional es:
PROMESA → COMPRENSIÓN → EVIDENCIA → MÉTODO → RUMBO.

## DISEÑO
- editorial, no dashboard técnico;
- imagen dominante;
- fondo claro/papel o noche ISL según destino;
- navy/teal/gold como acentos, no ruido;
- serif para voz/épica, sans para acción/estado;
- iconos pocos y funcionales;
- aire;
- bordes finos;
- anotaciones manuscritas sólo como capa humana;
- contraste legible en móvil e impresión.

## APLICACIÓN
Usar cuando aporte valor en:
- Rumbo ISL;
- briefs;
- playtests;
- Carrillo;
- PDFs;
- presentación física;
- propuesta a colaborador;
- handoff;
- checkpoint visual;
- asset/relic one-pager;
- making-of.

No convertir todas las pantallas en dossier.
Gameplay sigue siendo gameplay.

## REGLA DE ACTUALIZACIÓN
En checkpoint significativo:
- actualizar HECHO;
- mover sólo lo realmente activo a AHORA;
- limpiar DESPUÉS;
- mantener PRIMARY visible.

No crear un nuevo documento si basta con actualizar una superficie existente.

## CQC
- ¿entiendo qué es en 5 segundos?
- ¿hay una imagen protagonista?
- ¿sé qué está hecho?
- ¿sé qué toca ahora?
- ¿puedo actuar sin buscar otro documento?
- ¿hay menos texto del que había antes?
- ¿lo técnico sigue disponible sin ocupar portada?


## MASTER PDF EDITORIAL SYSTEM · 2026-09-28

Estado:
ACTIVE · MASTER EDITORIAL GRAMMAR FOR ISL PDFs · NO NEW ORGAN · SOURCE-OF-TRUTH EXTENSION

### DECISIÓN HUMANA
La gramática editorial nacida del dossier visual ISL de 5 páginas y del Brief de Bolsillo pasa a ser la PLANTILLA MAESTRA FUNCIONAL para documentos PDF de ISL cuando exista una superficie humana/editorial.

Esto NO significa:
- copiar siempre el mismo layout;
- convertir specs técnicas en folletos;
- decorar documentos con imágenes irrelevantes;
- ocultar precisión;
- sustituir SOURCE_OF_TRUTH técnico.

Significa:
ABSTRAER la misma manera de pensar y comunicar.

### MASTER PRINCIPLE
DOCUMENTO ISL =
PROMESA
→ ORIENTACIÓN
→ COMPRENSIÓN
→ EVIDENCIA
→ TENSIÓN / DECISIÓN
→ ACCIÓN
→ RUMBO
→ DETALLE AL FONDO.

La forma editorial debe reducir carga cognitiva sin reducir profundidad.

### HUMAN READING ORDER
Toda página humana debería poder leerse en 3 velocidades:

#### 2 SEGUNDOS
- qué estoy viendo;
- una imagen / forma dominante;
- una frase/titular;
- estado general.

#### 20 SEGUNDOS
- qué importa;
- qué cambió;
- qué decisión o pregunta existe;
- cuál es la relación entre elementos.

#### 2 MINUTOS
- evidencia;
- método;
- matiz;
- detalle técnico;
- siguientes pasos.

Si el documento sólo funciona leyendo todo el cuerpo pequeño, FAIL.

### WORD GRAMMAR
La fuerza del brief no viene sólo del layout.
También viene del lenguaje.

Preferir:
- frases con verbo;
- nombres concretos;
- títulos que hacen avanzar;
- palabras simples para ideas complejas;
- contraste semántico;
- ritmo corto/largo deliberado;
- una pregunta fuerte cuando ayuda;
- una frase humana que condense la página;
- labels pequeños sólo para orientar;
- lenguaje técnico sólo donde aporta decisión.

Evitar:
- títulos burocráticos;
- bloques abstractos sin verbo;
- redundancia entre titular/copy/imagen;
- “consultoría genérica”;
- llenar espacios porque sobran;
- convertir cada concepto en bullet;
- explicar dos veces la misma relación.

### VISUAL SENTENCE
Cada página debe poder describirse como una frase visual:

DOMINANTE
+ APOYO
+ RELACIÓN
+ SALIDA.

Ejemplos:
- IMAGEN GRANDE + TITULAR + 3 PILARES + UNA ACCIÓN.
- DIAGRAMA + CONTRADICCIÓN + EVIDENCIA + DECISIÓN.
- OBJETO + DETALLE + USO + ESTADO.
- VIAJE + HITOS + AHORA + DESTINO.

Si una página necesita 6 jerarquías simultáneas, simplificar.

### SCHEMAS / DIAGRAMS
Los esquemas forman parte de la identidad editorial cuando:
- hacen visible causalidad;
- ordenan una secuencia;
- comparan;
- muestran tensión;
- revelan dependencia;
- convierten complejidad en una lectura inmediata.

Tipos preferidos:
- A → B → C;
- THESIS ↔ ANTITHESIS → TEST;
- FROM → NOW → NEXT;
- INPUT → TRANSFORM → HUMAN GATE;
- 3 capas máximas;
- mapas de viaje/hitos;
- before/after;
- baseline/variant;
- matriz pequeña con una pregunta clara.

Evitar diagramas “de ingeniería” cuando una frase o imagen resuelve mejor.

### MASTER PAGE DNA
Elementos disponibles, no obligatorios:

1. EYEBROW / CONTEXTO
2. TITULAR
3. FRASE HUMANA
4. IMAGEN / DIAGRAMA DOMINANTE
5. 1–3 BLOQUES DE APOYO
6. ESTADO / CHECKFRAME
7. DECISIÓN / PREGUNTA
8. ACCIÓN / NEXT
9. FOOTNOTE / PROVENANCE / TECH

Orden de prioridad:
CONTENIDO → DECISIÓN → DETALLE.

### PAGE RHYTHM
Un buen PDF ISL no mantiene la misma densidad página tras página.

Alternar:
- apertura amplia;
- página explicativa;
- página de evidencia;
- página de tensión/comparación;
- página de decisión;
- respiro visual;
- cierre/ruta.

La respiración es parte del diseño.

No hacer:
12 páginas con seis cajas idénticas.

### IMAGE CONTRACT
La imagen debe responder a una pregunta.

Possible roles:
HERO
WORLD
EVIDENCE
DETAIL
COMPARE
PROCESS
MEMORY
CONSEQUENCE
MOOD
OBJECT.

Antes de insertar:
¿qué perdería la página si quitamos esta imagen?

Si la respuesta es “nada” → quitar.

### TYPOGRAPHIC FUNCTION
Serif:
- voz;
- promesa;
- mundo;
- emoción;
- cita/frase núcleo.

Sans:
- acción;
- estado;
- evidencia;
- datos;
- navegación;
- pequeños labels.

No usar tipografía como decoración temática.
Jerarquía > variedad.

### COLOR FUNCTION
Acentos ISL:
- navy / dark grounded field;
- teal / aire / sistema vivo;
- gold / señal / decisión / objeto importante;
- ivory / papel / respiración.

Regla:
un color debe significar algo o desaparecer.

No arcoíris de estados.
No paneles de SaaS.
No glow gratuito.

### MATERIALITY
PDFs físicos o imprimibles pueden usar:
- papel;
- grano;
- desgaste muy sutil;
- líneas finas;
- anotaciones humanas;
- marcas de registro;
- sellos;
- textura material.

Sólo si mejora presencia.
No convertir la legibilidad en cosplay editorial.

### PDF FAMILIES
La gramática maestra se adapta según función:

#### A · ONE-PAGER / BRIEF
PROMESA → OBJETIVO → HACER / NO HACER → CHECKFRAME → SALIDA.

#### B · DOSSIER / VISION
PROMESA → MUNDO → EVIDENCIA → MÉTODO → RUMBO.

#### C · PLAYTEST / HUMAN LAB
QUÉ PROBAR → CÓMO ENTRAR → QUÉ OBSERVAR → PREGUNTAS → RETURN.

#### D · TECH / IMPLEMENTATION HANDOFF
RESULTADO DESEADO → CONSTRAINTS → SCHEMA / FLOW → EDGE CASES → VERIFY → ROLLBACK.
Visualmente claro, pero precisión técnica intacta.

#### E · PHYSICAL / MANUFACTURING
OBJETO → DIMENSIONES → MATERIAL → FRONTAL/REVERSO → TOLERANCIAS → SAMPLE GATE → CQC.

#### F · NARRATIVE / WORLD / CREATURE
PROMESA → REGLA → CONTRADICCIÓN → COMPORTAMIENTO → CONSECUENCIA → HUELLA.

#### G · INVESTOR / COLLABORATOR
QUÉ ES → POR QUÉ IMPORTA → QUÉ EXISTE → EVIDENCIA → RUMBO → QUÉ SE NECESITA.

#### H · CHECKPOINT / HANDOFF
FROM → WHAT CHANGED → CURRENT → BLOCKER → SAFE NEXT → HUMAN GATE.

Misma gramática.
Distinto cuerpo.

### INFORMATION ABSTRACTION PIPELINE
Para convertir un documento crudo en PDF editorial:

RAW / SOURCE
→ EXTRAER DECISIONES
→ EXTRAER EVIDENCIA
→ EXTRAER RELACIONES
→ ELIMINAR DUPLICACIÓN
→ AGRUPAR EN 3–7 IDEAS
→ ELEGIR JERARQUÍA
→ ELEGIR VISUAL / DIAGRAMA
→ ESCRIBIR FRASE HUMANA
→ AÑADIR TECH/PROVENANCE AL FONDO
→ CQC HUMANO.

Nunca empezar por “hacerlo bonito”.

### CONTENT PRESERVATION RULE
La abstracción editorial puede:
- comprimir;
- ordenar;
- jerarquizar;
- visualizar;
- traducir lenguaje;
- mover detalle a anexos;
- separar capas.

No puede:
- inventar evidencia;
- borrar contradicciones;
- cambiar estado;
- promocionar candidatos;
- resumir hasta perder una condición crítica;
- embellecer una incertidumbre como certeza.

### MASTER TEMPLATE TEST
Antes de cerrar cualquier PDF ISL:

1. ¿se entiende sin explicación oral?
2. ¿la primera página tiene una promesa clara?
3. ¿cada página tiene una dominante?
4. ¿las palabras suenan humanas?
5. ¿los esquemas explican relaciones reales?
6. ¿la evidencia está separada de aspiración?
7. ¿el estado puede verse rápido?
8. ¿lo técnico está disponible sin ocupar el foco?
9. ¿hay suficiente aire?
10. ¿parece ISL sin necesidad de logos enormes?
11. ¿podría imprimirse y seguir funcionando?
12. ¿el documento ayuda a decidir algo?

### MASTER REFERENCE RULE
La referencia formal de máxima prioridad para esta gramática sigue siendo:
- dossier visual ISL de 5 páginas;
- Brief de Bolsillo / Carrillo cuando aplique;
- este CURRENT como abstracción funcional.

No copiar mecánicamente proporciones, cajas o textos del original.
Preservar:
claridad
+ ritmo
+ jerarquía
+ humanidad
+ esquemas útiles
+ lenguaje directo
+ aire
+ estado visible
+ cierre accionable.

### FUTURE PDF GENERATION
Cuando se genere un nuevo PDF ISL:
1. identificar familia A–H;
2. recuperar este CURRENT;
3. recuperar SOURCE_OF_TRUTH del contenido;
4. construir estructura editorial antes de maquetar;
5. usar imágenes sólo con rol definido;
6. aplicar checkframe cuando exista estado;
7. separar HUMAN LAYER / TECH LAYER cuando convenga;
8. validar pantalla + impresión;
9. registrar master editable + PDF exportado;
10. conservar provenance/versionado.

No crear una nueva plantilla estética por documento salvo necesidad demostrada.

### FINAL RULE
THE TEMPLATE IS NOT THE LOOK.

THE TEMPLATE IS:
HOW ISL THINKS
→ HOW ISL EXPLAINS
→ HOW ISL SHOWS EVIDENCE
→ HOW ISL LEAVES ROOM TO BREATHE
→ HOW A HUMAN KNOWS WHAT TO DO NEXT.


## ISL THEMATIC EDITORIAL SKIN · JOURNEY / HEART / CRESCENDO · 2026-09-28

Estado:
ACTIVE THEMATIC LAYER · APPLIES TO HUMAN-FACING ISL PDFs · NO NEW ORGAN · FUNCTIONAL THEMATIZATION

### WHY
La gramática editorial maestra no debe quedarse en claridad neutra.
Los documentos humanos importantes deben llevar dentro la misma respiración del juego.

Tema editorial =
VIENTO
+ VIAJE
+ NAVE/HOGAR
+ HORIZONTE
+ CRIATURAS
+ HUELLA
+ GRIETA
+ DESCENSO
+ ASCENSO
+ CREACIÓN / CONTINUACIÓN.

No como decoración literal.
Como ritmo, jerarquía, tensión, silencio, continuidad y materialidad.

### CORE JOURNEY
Cuando el documento admita recorrido narrativo, usar como curva profunda:

01 CUIDADO
→ 02 HORIZONTE
→ 03 CURIOSIDAD / OBSESIÓN
→ 04 CAÍDA
→ 05 REENTRADA / HOGAR
→ 06 PRESIÓN
→ 07 INFIERNO / UMBRAL
→ 08 ASCENSO / REENCUENTRO
→ 09 CREAR / CONTINUAR.

No todos los PDFs necesitan 9 capítulos.
Pero su ritmo puede derivarse de este arco:
entrada íntima
→ apertura
→ complejidad
→ tensión
→ caída
→ respiración
→ resolución provisional
→ salida con deseo.

### CRESCENDO RULE
Los documentos de visión, presentación, colaboración o narrativa deben construir intensidad.

No:
todas las páginas al mismo volumen.

Sí:
QUIET
→ OPEN
→ DISCOVER
→ PRESSURE
→ BREAK
→ BREATHE
→ RISE
→ CONTINUE.

La densidad, escala de imagen, tamaño de titular, oscuridad, contraste y espacio negativo pueden acompañar el crescendo.

### WIND AS EDITORIAL MOTIF
El viento puede aparecer de forma abstracta mediante:
- diagonales leves;
- flujo entre bloques;
- líneas de conexión;
- espacio negativo;
- movimiento visual izquierda→derecha / abajo→arriba;
- textiles/materiales en imagen;
- microanotaciones que parecen desplazadas por una corriente;
- mapas de ruta;
- respiración amplia alrededor de elementos.

Evitar:
- iconos de viento repetidos;
- remolinos decorativos;
- partículas gratuitas.

El viento debe ORIENTAR.

### SKYSHIP / HOME MATERIALITY
La nave-hogar puede inspirar materialidad editorial:
- madera gastada / latón / tela / papel / cuerda como referencia funcional;
- reparaciones visibles;
- objetos usados;
- pequeñas imperfecciones;
- calidez localizada;
- sensación de documento vivido, no corporativo.

No convertir PDF en interfaz steampunk.

Objetivo:
HOME + JOURNEY + USE.

### HORIZONTE
Toda pieza importante debe tener una sensación de destino.

Visualmente:
- apertura;
- aire;
- grandes márgenes;
- una línea de horizonte;
- una imagen o esquema que apunte a algo fuera de la página;
- cierre que no clausura.

Editorialmente:
WHAT EXISTS
→ WHAT CALLS US NEXT.

### CREATURE / WORLD PRESENCE
En documentos de mundo, criaturas o narrativa:
la criatura no aparece como ficha de bestiario por defecto.

Mostrarla como:
- presencia;
- conducta;
- relación;
- huella;
- escala;
- cambio por acto;
- consecuencia ecológica/social.

CREATURE ≠ CARD.
CREATURE = LIVING WORLD SIGNAL.

### TRACE / MEMORY
Una idea importante puede reaparecer más tarde transformada.

Ejemplos:
- mismo símbolo con distinto significado;
- misma frase reducida;
- objeto repetido;
- color que cambia de función;
- diagrama que vuelve simplificado;
- imagen del comienzo reflejada en cierre.

Esto crea CALLBACK EDITORIAL.

No repetir por branding.
Repetir para crear MEMORIA.

### RIFT / THRESHOLD
Para cambios de sección de alta importancia:
usar UMBRAL, no simple separador.

El cambio puede sentirse mediante:
- caída brusca de densidad;
- gran masa oscura;
- página casi vacía;
- ruptura de grid;
- cambio de orientación;
- una sola frase;
- contraste fuerte entre before/after.

Función:
“algo ha cambiado”.

No usar grietas literales en cada documento.

### DARK / LIGHT RHYME
Aplicar la misma regla del mundo:
oscuridad no es “poner fondo negro”;
ascenso no es “poner todo blanco/dorado”.

DARK:
más presión
+ menos información
+ foco estrecho
+ masa/silencio.

ASCENT:
más respiración
+ apertura
+ continuidad
+ memoria de la presión anterior.

El cierre debe conservar una cicatriz visual o semántica.
Nada vuelve exactamente al punto cero.

### MUSIC / RHYTHM TRANSLATION
Aunque un PDF no tenga audio, puede tener ritmo musical.

Traducir música a:
- repetición;
- pausa;
- crescendo;
- leitmotiv;
- silencio;
- síncopa;
- retorno transformado.

Una página puede actuar como “compás”.
Una doble página puede ser “cambio de movimiento”.

No maquetar mecánicamente por compases.
Usar ritmo como herramienta editorial.

### LANGUAGE THEMING
La voz editorial debe compartir el tono de ISL:

- directa;
- poética sólo cuando condensa;
- humana;
- un poco extraña;
- con humor lateral cuando corresponda;
- oscura sin grandilocuencia;
- tierna sin azúcar;
- épica sin marketing vacío.

Preferir frases como:
“Volvimos y el mundo se acordaba.”
“Lo que cambia deja huella.”
“Primero se siente. Después se explica.”
“Crear no cierra el viaje.”

Evitar:
“solución innovadora”, “experiencia disruptiva”, “ecosistema 360º”, “journey del usuario” salvo contexto técnico.

### HUMAN SCALE
Incluso en páginas de enorme escala:
preservar una ancla humana.

Puede ser:
- una silueta;
- una mano;
- una taza;
- una nota;
- una frase;
- una decisión;
- un error;
- una huella.

GRANDEZA SIN ANCLA HUMANA = FAIL ISL.

### THEMATIC PAGE ROLES
Cada página humana importante puede asumir UN rol dominante:

HARBOR
HORIZON
DISCOVERY
PRESSURE
RIFT
DESCENT
RETURN
ASCENT
CREATION.

El rol influye en ritmo y composición, no impone contenido literal.

FROM / RIFT → NOW → RETURN → NEXT HORIZON.

### LANDING ↔ PDF COHERENCE
La landing GAME VISION y los PDFs humanos deben sentirse hijos del mismo mundo.

Compartir:
- arco emocional;
- aire;
- jerarquía;
- materialidad;
- frase corta;
- imágenes con función;
- continuidad;
- escalada;
- memoria;
- cierre abierto.

No compartir mecánicamente:
- mismos bloques;
- mismas animaciones;
- mismas composiciones;
- mismos textos.

ONE GAME · DIFFERENT SURFACES.

### THEMATIC CQC
Antes de cerrar un PDF humano:
1. ¿se siente viaje o sólo documentación?
2. ¿hay una entrada tranquila?
3. ¿hay al menos una apertura/horizonte?
4. ¿existe un cambio de presión o tensión cuando procede?
5. ¿hay respiración?
6. ¿algo vuelve transformado?
7. ¿hay una ancla humana?
8. ¿las criaturas/mundo aparecen como vida y no catálogo?
9. ¿el documento termina abriendo rumbo?
10. ¿sigue siendo legible si quitamos toda ornamentación temática?

Si la tematización compite con claridad:
CLARITY WINS.
Si la claridad elimina toda alma:
MUTATE UNTIL BOTH SURVIVE.

### FINAL THEMATIC RULE
THE PDF SHOULD NOT LOOK LIKE THE GAME.

IT SHOULD FEEL AS IF IT CAME FROM THE SAME JOURNEY.
