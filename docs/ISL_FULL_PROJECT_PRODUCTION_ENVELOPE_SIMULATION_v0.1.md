## 2 · CRITICAL ASSUMPTION
A 5-minute runner can execute up to 288 wake-ups/day.
It must NOT be treated as 288 useful production actions/day.

Most wake-ups should be:
NO-OP / VERIFY / DEDUP / STATUS / HANDOFF.

Effective verified throughput is limited by:
- provider quotas;
- human review;
- asset quality;
- rework;
- Unreal integration;
- testing;
- dependencies;
- IP/provenance;
- device validation.

AUTOMATION COMPRESSES WAITING AND TRANSCRIPTION.
IT DOES NOT REMOVE CREATIVE OR INTEGRATION WORK.

## 4 · VERIFIED-ASSET THROUGHPUT MODEL
These are SIMULATION RATES, not provider limits.

### 2D / IMAGE
AI can produce many candidates quickly.
Verified production throughput:
- concept/support image: 4–12 usable/day in active batch;
- strong hero/key image: 1–3 verified/day;
- crown-jewel image: 0–1/day after source lock + human read.

### 3D
AI can generate quickly, but runtime-ready throughput is slower.

Verified production throughput assumption:
- simple prop family: 2–5/day after pipeline stabilizes;
- medium environment/interactive asset: 1–2/day;
- hero creature/character/relic: 0.3–1/day;
- runtime-ready character/creature with animation/rig/material/LOD/collision/test may consume multiple person-days.

### AUDIO / MUSIC
- exploratory cue: several/day;
- verified major theme/scene cue: 0.5–2/day;
- integrated/mastered/looped/game-ready audio requires later implementation and QA.

### GAMEPLAY / ENCOUNTER
After framework stabilizes:
- simple encounter/content unit: 1–3 verified/day;
- complex authored set-piece: 2–8 person-days;
- boss/high-concept sequence: 1–4+ weeks including iteration depending scope.

### UNREAL INTEGRATION
Automation helps imports/validation.
It does NOT eliminate:
- Blueprint/C++ logic;
- materials/shaders;
- animation;
- collision;
- performance;
- save integration;
- gameplay tags/data;
- streaming;
- controller/device;
- packaged tests.

## 5 · AUTOMATION FACTOR
Without automation:
high manual coordination / transcription / queue overhead.

With 5-minute mechanical runner + adapters:
estimated schedule compression after pipeline maturity:
- admin/coordination: 40–70%;
- provider handoff / asset tracking: 30–60%;
- repeated metadata / validation: 50–80%;
- content candidate preparation: 30–60%;
- final creative judgment: ~0%;
- deep gameplay design: 0–20%;
- Unreal integration: 10–30%;
- QA/rework: 10–30%.

Overall project elapsed-time compression:
SIMULATION RANGE ~15–30%, not 90%.

Why:
the critical path moves from “waiting for prompt” to
“is it actually good, integrated, tested and fun?”

## 8 · WHY 5-MIN PROMPTS DO NOT MAKE IT A 6-MONTH PROJECT
A 5-minute runner may prepare thousands of candidates.
But A++ production requires:
CANDIDATE
→ SELECT
→ SOURCE LOCK
→ EDIT / MUTATE
→ IMPLEMENT
→ INTEGRATE
→ PERFORMANCE
→ REGRESSION
→ DEVICE
→ HUMAN
→ REWORK
→ LOCK.

The runner accelerates the arrows.
It does not delete them.
