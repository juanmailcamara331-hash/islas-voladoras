## PWA
Objetivo:

Pasos:
Chrome -> ISL Center -> menú -> Instalar aplicación / Añadir a pantalla de inicio.
Dentro:
Avisos ISL -> Activar notificaciones -> Probar aviso.

## ALTAR ISL
Compra mínima:
- cofre pequeño;
- luces cálidas;
- 6 botellas;
- cuerda;
- etiquetas kraft;
- brújula o reloj de arena.

Regla:
- CANON -> entra una reliquia;
- CHECKPOINT -> un nudo;
- REGIÓN -> nueva botella;
- CANCIÓN aprobada -> tarjeta QR;
- RECHAZADO aprendido -> bolsa negra, no basura.
