# ISL_REFERENCE_FUNCTION_AND_COHERENCE_PROTOCOL_CURRENT

Estado: PROVISIONAL FUERTE · TRANSVERSAL
Fecha: 2026-09-21

## OBJETIVO
Usar libros, juegos, cine, arte, filosofía, música, arquitectura y cultura como motores funcionales sin convertir ISL en collage.

## CADENA
FUENTE → FUNCIÓN → PRINCIPIO → CONTRADICCIÓN → MUTACIÓN ISL → PROTOTIPO → CQC → EVIDENCIA → DECISIÓN

## PARA CADA REFERENCIA
Registrar:
- qué problema resuelve;
- qué sensación produce;
- cómo mantiene coherencia a lo largo del tiempo;
- qué mecanismo usa;
- qué NO debemos copiar;
- qué contradicción introduce con ISL;
- qué versión propia puede nacer.

## COHERENCIA DE OBRAS LARGAS
Cuando una referencia tenga universo amplio (ej. Terry Pratchett):
- estudiar recurrencias, no una sola escena;
- observar cómo cambia el mundo sin perder identidad;
- distinguir reglas estables de excepciones;
- observar callbacks, consecuencias y personajes recurrentes;
- analizar cómo el humor convive con stakes reales;
- extraer gramática, no ornamentación.

## TEST ANTI-COLLAGE
Una referencia sólo permanece activa si:
1. cumple una función concreta;
2. puede explicarse sin nombrar la obra original;
3. al cruzarla con ISL produce algo nuevo;
4. no requiere imitar superficie reconocible;
5. aumenta coherencia o potencia una contradicción fértil.

Si no, PARK/KILL.
