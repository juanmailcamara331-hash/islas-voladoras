# ISL — SÍNTESIS DE PILARES · PLANTILLA v0.64
Fecha: 2026-09-18
Estado: ACTIVA · usar tras primeras respuestas humanas

## Regla
La encuesta NO decide canon por mayoría.
Se cruza con:
- tesis de diseño;
- antítesis;
- evidencia externa;
- prototipos;
- CQC;
- decisión humana.

## Cohortes
No mezclar sin etiqueta:
- AMIGOS
- JUGADORES_OBJETIVO
- PUBLICO_GENERAL
- FOCUS_NARRATIVO

## Lectura mínima
Para cada pregunta registrar:
- patrón dominante;
- disenso relevante;
- confusión recurrente;
- señal débil interesante;
- contradicción entre respuestas;
- diferencia por cohorte.

## Síntesis 1 página
### 1. QUÉ SE QUEDA
Pilares comprendidos y reforzados por evidencia.

### 2. QUÉ NECESITA ACLARACIÓN
Elementos valiosos pero mal comunicados.

### 3. QUÉ PASA A PROTOTIPO
Contradicciones que no se resuelven opinando y requieren experiencia jugable.

### 4. QUÉ ESPERA / SE RECORTA
Capas que añaden ruido o no justifican coste todavía.

### 5. RIESGO PRINCIPAL
Una frase.

### 6. HIPÓTESIS SIGUIENTE
Una hipótesis falsable para el siguiente prototipo.

## Stop criteria
No ampliar sistemas si aparece cualquiera:
- objetivo principal confuso de forma recurrente;
- promesa jugable poco entendida;
- tono y mecánica se contradicen;
- demasiadas capas compiten por atención;
- evidencia humana contradice una suposición central y aún no hay prototipo que la resuelva.

## No-promoción automática
- puntuación alta != CANON;
- popularidad != verdad;
- una minoría puede revelar una contradicción real;
- una respuesta aislada no invalida un sistema sin contexto.

## Orden posterior
PILARES → SÍNTESIS → 3 CRIATURAS → NUDOS → CQC B×A → DECISIÓN HUMANA.
