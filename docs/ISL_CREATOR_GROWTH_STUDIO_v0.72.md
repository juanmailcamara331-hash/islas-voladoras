1. MAKING ISL — devlog, proceso, errores, decisiones, checkpoints.
2. ACADEMIA / CURSO — lecciones extraídas del proceso real; nunca vender humo ni revelar material privado.
3. STREAM / SEMI-LIVE — sesiones filtradas de creación, playtests y laboratorio; no mostrar credenciales, repos privados, datos de testers, rights-sensitive material ni roadmap privado.
4. SUPPORTER / PREMIUM LEARNING — acceso ampliado a proceso, breakdowns, materiales educativos y making-of.
5. CAMPAÑAS / CROWDFUNDING — sólo tras evidencia; wishlist, comunidad y señal de demanda separadas de CANON.
6. MOCKUPS / PHYSICAL — dossier, cartas, mapas, objetos, petacas/merch y otros conceptos: MOCKUP → INTEREST TEST → WAITLIST/PREORDER → SMALL BATCH/POD.
7. DOCUMENTARY / HOW IT WAS MADE — Creation Process Ledger como materia prima.
8. CRM / AUDIENCE — estados CURIOUS / LEARNER / TESTER / SUPPORTER / CAMPAIGN_INTEREST / CORE_COMMUNITY; consentimiento por finalidad; no score humano.
