## NORTH STAR
ONE WORLD · ONE JOURNEY · MANY REPRESENTATIONS.

Every subsystem must answer:
- what player promise does this serve?

## NO DOPAMINE-HACKING RULE
Do not design around vague dopamine claims.
Use observable variables:
EXPECTATION · SURPRISE · EFFORT · UNCERTAINTY · MASTERY · FRUSTRATION · REST · REWARD · CONSEQUENCE · MEMORY · VOLUNTARY REPLAY.

Candidate experience curve:
ROUTINE → FRICTION → MASTERY → EXPECTATION → SURPRISE → DECISION PEAK → CONSEQUENCE → DESCENT → CALM → RE-READING.

## GAME-THEORY / COMPLEX-GAME CROSS
Use complex tabletop/card-game lessons by function only.

Abstract useful dimensions:
- hidden vs public information;
- tempo / initiative;
- opportunity cost;
- resource conversion;
- delayed payoff;
- bluff / signalling;
- dominant strategy detection;
- counterplay;
- combinatorial depth;
- local simplicity vs global complexity;
- asymmetry;
- comeback mechanisms;
- lockout prevention;
- meaningful sacrifice;
- deck/build/loadout identity;
- emergent interactions.

Rule:
COMPLEX SYSTEMS ARE ACCEPTED ONLY IF LOCAL DECISIONS REMAIN LEGIBLE.

For any mechanic:
CHOICE SET
→ INFORMATION AVAILABLE
→ RESOURCE COST
→ OPPONENT/WORLD RESPONSE
→ SHORT CONSEQUENCE
→ LONG CONSEQUENCE
→ COUNTERPLAY
→ EXPLOIT RISK
→ REPLAY VALUE.

Do not copy Magic or any specific game's surface/mechanics verbatim. Abstract decision structure only.

## DIALECTIC FOR SYSTEM DESIGN
THESIS: the simplest readable mechanic.
ANTITHESIS: the strongest meaningful complication.
SYNTHESIS: preserve the smallest rule set that creates the desired strategic/emotional depth.

If complexity adds explanation but not better choices, remove it.
