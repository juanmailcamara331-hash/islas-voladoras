# ISL — REFERENCE INTAKE SURVEY METHOD v0.49
Fecha: 2026-09-18
Estado: ACTIVO · carril de evidencia social, no canon automático

## Propósito
Usar encuestas breves a amigos/jugadores para detectar qué funciones creativas tienen energía real antes de incorporarlas a ISL.

## Regla madre
La gente no vota “qué copiar”. Vota qué función, sensación o contraste merece ser explorado.
Toda referencia externa se transforma mediante:
referencia → función → contraste → prototipo barato → CQC → decisión humana.

## Cómo interpretar resultados
No usar mayoría simple como orden automática.
Medir:
1. FUNCIÓN — qué aporta: jugabilidad, narrativa, visual, música, sistema, humor.
2. INTENSIDAD — cuánto suma a ISL.
3. ESCALA — pincelada / subreferencia / referencia fuerte / descartar.
4. RIESGO — qué no debería copiarse.
5. NOVEDAD — nuevas referencias propuestas.
6. CONVERGENCIA — si varias personas describen la misma función con palabras distintas.

## Regla de promoción
ENCUESTA → evidencia social, no decisión.
Para subir peso:
- mínimo 2 funciones fuertes;
- compatibilidad con identidad ISL;
- riesgo de derivación controlado;
- prototipo barato que demuestre valor;
- CQC;
- aprobación humana.

## Regla de diversidad
No dejar que una muestra de amigos sustituya públicos distintos.
Etiquetar resultados como FRIENDS_SAMPLE.
Más adelante separar:
- amigos cercanos;
- jugadores externos;
- gente ajena al proyecto;
- especialistas cuando una referencia lo necesite.

## Anti-sesgo
- evitar preguntar “¿te gusta X?” como única métrica;
- preguntar qué función funciona y qué debería evitarse;
- incluir “mejor no usarla”;
- permitir referencias alternativas;
- conservar respuestas abiertas;
- no convertir nostalgia/reconocibilidad en argumento suficiente.

## Integración con matriz
Toda referencia propuesta por encuesta entra primero como CANDIDATA / peso provisional.
Sólo se añade al master tras revisión de provenance, funciones y riesgo.
