# ISL — PRE-AUDITORÍA v0.11

Este repositorio conserva prototipos históricos y pasa a formar parte de la infraestructura de ISLAS VOLADORAS / ISL.

## Fuente de verdad

1. **Biblia Maestra**: manda sobre CANON y estado del diseño.
2. **Archivo Total**: conserva ideas; aparecer allí no equivale a CANON.
3. **Registro de decisiones**: explica qué cambió, por qué y cómo se probará.
4. **Auditoría Magistral / CQC-R**: laboratorio; puede cuestionar decisiones sin promover hipótesis silenciosamente.

Los documentos maestros binarios se archivan en Google Drive. GitHub se reserva para código, configuración, scripts, validadores, tests y documentación técnica versionable.

## Principios de producción

- IDEA → DEFINICIÓN → PROTOTIPO → PRUEBA → DECISIÓN → FIJAR → SIGUIENTE.
- Automatizar maquinaria, no alma.
- IA propone → sistema valida → humano decide.
- Regla 1–3–∞: 1 prueba mínima, máximo 3 conexiones iniciales, potencial combinatorio posterior.
- No reducir profundidad para reducir complejidad; eliminar complejidad que no produce profundidad perceptible.
- No proteger trabajo previo por coste hundido.
- Una decisión importante que sólo existe en chat todavía no existe suficientemente.

## CQC-R

CONSTRUIR → CQC local → CORREGIR → CRUZAR → CQC relacional → CQC del método → DECISIÓN → REGISTRO.

Parada: si otra vuelta de revisión no cambia ninguna decisión, se detiene.

## Próximo orden
