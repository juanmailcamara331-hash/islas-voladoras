# ISL — MISIÓN DE CAZA 002 · CABINA DE CARTÓGRAFO
Estado: ABIERTA
Objetivo: completar funciones físicas, no decorar por decorar.

## PRIORIDAD ALTA
1. **Cuerda fina usada / cordón con carácter**
   → Línea de Viaje. Un nudo por checkpoint importante.

2. **Campanilla pequeña real**
   → Campana de Canon. Sólo suena cuando algo cruza un gate de verdad.

3. **Brújula vieja o instrumento de orientación**
   → Orientador. Mejor si está gastado o imperfecto.

4. **Bolsa negra / estuche pequeño**
   → Archivo de Mundos que No Fueron. Rejected-learned físico.

5. **Caja/cofre/cajón viejo**
   → Archivo de Corrientes. Debe poder crecer; evitar "cofre pirata" de disfraz.

## PRIORIDAD MEDIA
- etiquetas de equipaje antiguas;
- llaves sin cerradura;
- mapas viejos;
- postales;
- pequeños marcos;
- retales de tela;
- sellos/tampones;
- fichas metálicas;
- prismáticos viejos;
- reloj roto;
- piezas de latón o madera con uso anterior.

## NO COMPRAR
- calaveras pirata de bazar;
- monedas "fantasy" falsas;
- brújulas decorativas nuevas sin historia;
- engranajes steampunk aleatorios;
- objetos voluminosos sin función.

## BONUS
Encontrar un objeto cuya función real NO sepamos.
Esos son candidatos perfectos para "Objeto de Uso Perdido".
