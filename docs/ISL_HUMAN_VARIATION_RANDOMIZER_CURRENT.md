# ISL · HUMAN VARIATION RANDOMIZER · CURRENT
Fecha: 2026-09-22
Estado: ACTIVE · TRANSVERSAL · ISL ONLY

## PRINCIPIO
La variación no debe sentirse como azar de máquina.
Debe sentirse como respiración humana.

ISL no busca ocultar procedencia ni falsificar autoría.
Busca evitar uniformidad, plantillas repetitivas, perfección estéril y tono de asistente.

Regla:
VARIAR FORMA / PROFUNDIDAD / MEDIO / RITMO / DESTINO
SIN ALTERAR SOURCE_OF_TRUTH, HECHOS, SEGURIDAD, SPECS, CÓDIGO CRÍTICO NI CANON.

## PERFILES DE ENERGÍA

- JUGUETON: humor, sorpresa, 2–4 capas.
- ONIRICO: imagen, sonido, simbolismo, 2–5 capas.
- PUNK: contraste, ruptura controlada, 2–4 capas.
- CANSADO_BONITO: baja fricción, pieza breve, 1–2 capas.

Si el usuario expresa claramente una energía en la conversación, respetarla.

## RANDOMIZER CONTROLADO
No usar azar puro.

1. anti-repetición;

3. coste mínimo;
4. potencial de reutilización;

## HUMAN TEXTURE PASS
Permitido:
- asimetría compositiva;
- respiraciones;
- silencios;
- frases no perfectamente pulidas;
- gestos pequeños;
- humor lateral;
- materiales imperfectos;
- encuadres menos perfectos;
- señales de uso;
- ritmo variable;

- falsificar procedencia;
- inventar testimonios;
- fingir autoría humana;
- romper accesibilidad;
- degradar legibilidad por “estética humana”.

## SECTOR / REFERENCE WEIGHTED RANDOMIZER · 2026-09-22

El randomizer puede variar no sólo forma/medio/destino, sino también el campo de conocimiento desde el que nace una pieza.

### SECTORES
Familias elegibles:

- museografía / archivo;
- derecho / rights / provenance;
- marketing / editorial / framing.

### SELECCIÓN
Para outputs creativos:
- 1 sector cercano por defecto;
- 0–1 sector lejano opcional;
- 1–5 calas según necesidad real;
- la pieza puede ser directa, tool-assisted o multicapa;
- una cala buena gana a cinco capas forzadas.

### PESOS ADAPTATIVOS
No usar pesos fijos universales.
Calcular silenciosamente según:
1. relevancia al PRIMARY;
2. anti-repetición reciente;
3. capacidad de cambiar una decisión/experiencia;
4. coste;
5. sorpresa útil;
6. potencial de segunda vida.

Sectores usados recientemente pierden peso temporal.
Sectores ausentes durante varias iteraciones pueden recuperar peso si son pertinentes.

### REFERENCE MODE
Elegir también uno de estos modos:
- NONE;
- FUNCTIONAL_LIGHT;
- SECTOR_REFERENCE;
- HISTORICAL_REFERENCE;
- LATERAL_REFERENCE;
- DUAL_FUNCTIONAL_CROSS.

La referencia nunca es obligatoria.
NONE debe conservar probabilidad significativa para evitar outputs siempre derivados de referencias.

### DISTANCE MUTATION
Si una referencia domina demasiado:
- cambiar medio;
- cambiar estructura;
- cambiar material;
- cambiar contexto;
- cambiar función;
- introducir una contradicción ISL;
- o eliminar la referencia.

REFERENCE DISTANCE siempre prevalece sobre sorpresa.

### ANTI-REPETITION EXTENDIDO
Evitar repetir consecutivamente la misma combinación de:
- sector;
- pareja de sectores;

El randomizer no sólo elige QUÉ crear; también CÓMO ejecutarlo.

Modos:

- EXTERNAL_TOOL_PROMPT;

Motivo:

External tools ganan peso cuando:
- existe una capacidad específica no disponible directamente;
- vídeo/motion requiere una herramienta externa;
- 3D/scan requiere Meshy/Kiri u otra herramienta;
- se busca deliberadamente contraste A/B/C;

preservar identidad, composición, material, proporción, desgaste, cámara e iluminación salvo mutación explícita.


## DADO DE LO IMPROBABLE · ORCHESTRATOR-LINKED SERENDIPITY TRIGGER · 2026-09-28

Estado:
ACTIVE CREATIVE TRIGGER · LOW-FREQUENCY · HUMAN-GATED · NO AUTO-CANON · NO NEW BOT

### PURPOSE
Introducir de vez en cuando una perturbación creativa genuinamente inesperada sin convertir ISL en ruido ni permitir que el azar gobierne el proyecto.

El dado NO decide.
El dado sólo propone una desviación.

DIE
→ RANDOMIZER
→ ORCHESTRATOR ROUTING
→ CHEAP TEST / ARTIFACT
→ HUMAN READ
→ KEEP / MUTATE / PARK / KILL
→ RETURN PRIMARY.

### WHEN IT MAY ROLL
El dado puede activarse:
- por orden humana explícita: DADO / TIRA / LOCURA / PUM RARO;
- durante una sesión creativa cuando M4 detecta exceso de rigidez o repetición;
- en un pase de serendipia ya autorizado;
- excepcionalmente por el runner externo como PROPOSAL_ONLY cuando exista una ventana creativa marcada y no haya blocker humano.

No debe activarse:
- durante incidentes;
- seguridad / legal / permisos / secretos;
- migraciones;
- save/schema;
- builds críticos;
- fabricación;
- compras;
- publicación;
- HUMAN GATE pendiente;
- cuando el PRIMARY necesita una corrección concreta;
- para llenar tiempo.

### BASE FREQUENCY
Default:
LOW.

Suggested creative frequency:
~1 meaningful roll per 1–3 focused creative sessions,
or manual only when the human requests it.

The external 5-minute runner MUST NOT roll every 5 minutes.
It may only enqueue a DICE_OPPORTUNITY signal.
The actual creative roll is routed later through the slow creative loop.

### D6 · LEVEL OF DEVIATION

1 · MICRO-ODDITY
One tiny anomaly:
sound, object, gesture, material, line, creature behavior, UI micro-event.

2 · LATERAL CONNECTION
Connect current subject with one distant sector/function.

3 · MEDIUM MUTATION
Change one meaningful axis:
scale, temporal order, relation, material, point of view, physical law, social consequence.

4 · CONTRADICTION INJECTION
Add one productive contradiction that forces a new reading.

5 · CROSS-MEDIUM MUTATION
Translate function into another medium:
music → creature behavior;
object → rule;
dialogue → UI trace;
weather → combat rhythm;
physical relic → world event.

6 · WILD CARD / IMPOSSIBLE BUT LEGIBLE
Generate one high-surprise hypothesis that appears wrong at first but can be tested cheaply.
Must still preserve:
SOURCE
+ FUNCTION
+ ISL IDENTITY
+ REVERSIBILITY.

### OPTIONAL SECOND D6 · DOMAIN
Only roll if first result benefits from domain variation.

1 WORLD / SPACE
2 CREATURE / CHARACTER
3 GAMEPLAY / SYSTEM
4 AUDIO / MUSIC / RHYTHM
5 PHYSICAL / MATERIAL / OBJECT
6 META / FOURTH-WALL / HUMAN TRACE

Do not roll more than two dice by default.
More randomness usually reduces authorship.

### OPTIONAL DIAL · STRANGENESS
0 = NONE
1 = TRACE
2 = NOTICEABLE
3 = STRANGE
4 = EDGE
5 = LAB ONLY

Default cap:
3.

4–5 require explicit HUMAN CREATIVE WINDOW or LAB context.
Never allow 5 to propagate automatically into production.

### ORCHESTRATOR CONNECTION
After the die result, route through the smallest relevant set:

Always:
M0 NAVIGATION
+ M2 SOURCE / ENTITY
+ M1 QUALITY.

Then add only what changes the decision:
- creative artifact / surprise → M4;
- human response → M3;
- world / causal mutation → M10;
- image/audio/video/3D → M11;
- future Unreal consequence → M8;
- build/prototype → M9;
- formula/probability → M12;
- rights/security concern → M5.

Do not activate every layer because a die was rolled.

### RANDOM ≠ ARBITRARY
A valid roll must still satisfy at least 2 of:
- creates surprise;
- reveals hidden relation;
- changes player perception;
- produces a memorable object/event;
- deepens contradiction;
- increases replay/re-reading;
- creates useful humor;
- creates a new causal consequence;
- opens a cheap test;
- exposes a weakness in current design.

If none:
REROLL ONCE maximum or PARK.

### WILD EXAMPLES
Examples are illustrative, not commands:

- a creature learns the rhythm of a damaged ship part and starts predicting storms;
- a shop only appears when the crew has been arguing for too long;
- a relic changes no stat but makes certain NPCs remember the player incorrectly;
- a battle rhythm temporarily syncs with a domestic ship routine;
- an island's weather reacts to unfinished conversations rather than player location;
- a supposedly decorative physical object becomes the safest navigation cue in a dangerous section;
- a joke introduced early returns twenty hours later as a world rule;
- a defeated boss becomes environmental infrastructure instead of loot.

### ANTI-CHAOS GUARD
FAIL if:
- random result replaces current goal;
- becomes lore merely because it is weird;
- requires major production before a cheap test;
- copies recognizable external surface;
- invalidates established rules without consequence;
- creates “LOL random” tone;
- repeats the same kind of weirdness;
- becomes compulsory system;
- automation promotes it because it was generated.
