# ISL_MAGISTRAL_LAZY_CREATIVE_SESSION_PROTOCOL_CURRENT

Estado: CANON METODOLÓGICO · ISL ONLY
Fecha: 2026-09-21

## PROPÓSITO
Repetir sesiones creativas de alta energía, gran producción y baja fricción sin perder foco, memoria, seguridad ni capacidad de volver al PRIMARY.

## PATRÓN DE SESIÓN
1. ANCLA
   - recordar DE DÓNDE VENIMOS → DÓNDE ESTAMOS → QUÉ BLOQUEA → QUÉ HACEMOS AHORA.
   - identificar PRIMARY y gates.
2. PERMISO DE COLOR
   - abrir una lane temporal (Physical / Human / Narrative / Visual / Recreo) sin confundirla con PRIMARY.
   - declarar qué NO se toca.
3. CREACIÓN RÁPIDA
   - generar mockups, textos, objetos, ideas y variantes de alta señal.
   - priorizar piezas concretas sobre abstracciones interminables.
4. CRUCE ÚTIL
   - cada idea cruza máximo 1–3 sistemas existentes.
   - si requiere sistema nuevo, PARK.
5. HUELLAS HUMANAS
   - capturar personas, vivencias, feedback o hazañas relevantes mediante el protocolo de huellas.
6. MATERIALIZACIÓN
   - cuando una idea gane fuerza, convertirla en pieza: mockup, print candidate, prototipo, dossier, sesión humana o build.
7. PERSISTENCIA
   - decisión/metodología relevante → Drive.
   - operación/guard/código/protocolo → GitHub.
   - checkpoint si cambia continuidad futura.
8. SEGURIDAD
   - PUBLIC-SAFE / REDACTED para material externo.
   - secretos fuera de Chat/Drive/GitHub.
   - human review para acciones HIGH.
9. STOP RULE
   - detener expansión cuando otra vuelta no cambia decisión, riesgo o experiencia perceptible.
10. REGRESO
   - cerrar con: qué nació / qué queda protegido / qué vuelve al PRIMARY / siguiente gate.

## PRINCIPIO
MAGISTRALMENTE VAGO ≠ DESCUIDADO.
Significa:
- automatizar repetición;
- eliminar fricción;
- proteger la creatividad;
- guardar sólo lo que cambia algo;
- gastar energía humana en decisiones, mundo y relaciones.

## CADENCIA RECOMENDADA
TANDA LIBRE:
crear → variar → reír → materializar.

TANDA DE CIERRE:
clasificar → deduplicar → persistir → guard → checkpoint → volver al PRIMARY.

## SALIDAS
Cada objeto/idea termina como:
- MOCKUP;
- PRINT_CANDIDATE;
- COLOR_LANE;
- SEED;
- PROTOTYPE_CANDIDATE;
- ACTIVE;
- PARK;
- KILL;
- CANON_CANDIDATE (nunca CANON automático).
