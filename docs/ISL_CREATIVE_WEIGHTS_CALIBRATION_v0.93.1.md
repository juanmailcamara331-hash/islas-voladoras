## CREATIVE WEIGHT AXES
These are tunable review weights, NOT fixed scores and NOT player-facing systems.

### W1 · HUMAN HEART
Question: does this touch relation, care, desire, fear, belonging, loss, humour or consequence between beings?
Low = spectacle without lived consequence.
High = human meaning survives even if visuals are stripped.

### W2 · PLAYABLE MUSCLE
Question: does the player actually DO something different?
Low = lore/visual only.
High = changes verb, affordance, route, timing, tradeoff or interaction.

### W3 · WORLD CAUSALITY
Question: does the idea obey a legible rule with consequences?
Low = random weirdness.
High = local rule → systemic effect → human effect.

### W4 · MEMORY / RETURN
Question: can this acquire meaning later?
Low = disposable beat.
High = callback, persistent trace, delayed consequence, replay re-reading.

### W5 · SOCIAL MICRO-WORLD
Question: does the community/institution around the mechanic become legible and alive?
Useful reference functions: Pratchett + Recess/La Banda del Patio.

### W6 · OUTSIDER / DARK-TENDER
Question: does strangeness make us care more, not merely look stranger?
Useful reference function: Burton, heavily distance-mutated.

### W7 · HIGH-CONCEPT IRREVERENCE
Question: is there permission to break a large assumption and then treat the consequence with human/casual irreverence?
Useful reference function: Rick-like high-concept irreverence, never surface imitation.

### W8 · ARCHETYPAL TRANSFORMATION
Question: does the event reveal or bend a recurring pattern of behaviour/relationship without labeling the player?
Useful reference family: Jung / emergent archetypal thinking.

### W9 · NEUROPERCEPTIVE LEVERAGE
Question: is there an expectation first, then a legible violation, action, consequence and later memory?
Useful research family: prediction error / perception-action / memory.

### W10 · PUNK MATERIALITY
Question: does the piece feel used, hacked, improvised, disobedient or materially alive?
Guard: not costume-punk and not noise by default.

### W11 · PRISM / LIMINAL FUTURISM
Question: does the idea suggest permeability between rules/states/worlds without prematurely opening a multiverse feature?
Possible signals: phosphorescence, temporal mismatch, impossible reflection, artefact residue, refracted causality.
Guard: rare/local, not universal wallpaper.

### W12 · NORMALITY CONTRAST
Question: is there enough ordinary life around the anomaly for the anomaly to mean something?
High weight is often healthy.

### W13 · HUMOUR / LATERALNESS
Question: can the world be funny because of its logic, institutions and people rather than inserted jokes?

### W14 · VISUAL / AUDIO SKIN
Question: does presentation amplify an already-working internal function?
Guard: skin cannot compensate for absent heart/muscle/causality.

### W15 · ENTROPY

1 FRICTION

3 FRACTURE
4 PRISM
Entropy is a dose, not quality.

## REFERENCE WEIGHTS · DEFAULT CALIBRATION
NONE must always remain possible.
Default recommendation for a creative probe:
- 1 primary functional reference at medium weight;
- optionally 1 distant/lateral reference at low weight;
- all others at zero unless the piece genuinely needs them.

Suggested starting tendencies for THIS calibration period:
- Terry Pratchett: medium-high for institutions/social absurdity/humane consequence.
- Recess / La Banda del Patio: medium-high for micro-society/tribes/friendship/intuitive social rules.
- Tim Burton: low-medium, mostly outsider/dark-tender/silhouette emotion.
- Rick-like irreverence: low-medium globally, high only in bounded fracture/Prism moments.
- Jung: medium as hidden transformation lens, zero as explicit class picker.
- Neurobiology/cognitive science: medium-high as test logic, not aesthetic theme.

These are starting weights only. They may be raised/lowered by evidence and anti-repetition.

## RANDOMIZER SHOT FORMAT
For each calibration shot choose:
- SUBJECT / SOURCE_OF_TRUTH
- ORGAN TARGET: heart / muscle / nervous / blood / memory / skin / immune / lungs / brain / skeleton
- 2–4 weighted axes maximum
- 0–2 functional references
- entropy 0–4
- one explicit tension
- one cheapest perceptible microtest
- one failure condition
- one rollback path

Then generate 3 variants maximum:
A · closer / safer
B · lateral / social-human
C · wild / fracture-prism

Decision set:
KEEP / MUTATE / PARK / KILL / REROLL.

## DAILY CALIBRATION RHYTHM · OPTIONAL
Not a schedule/automation by itself.
Useful session shape:
1. recover one real piece;
2. choose 2–4 weights;
3. fire 3 shots maximum;
4. compare against baseline;
5. record what actually changed;
6. lower weights that are becoming repetitive;
7. raise missing functions only when justified;
8. stop before theory-sprawl.

## ANTI-COLLAGE / ANTI-TEMPLATE
Failure signals:
- every scene becomes weird;
- every scene uses phosphorescent green;
- every social system sounds Pratchett-like;
- every outsider reads Burton-like;
- every impossible event feels Rick-like;
- every behaviour gets Jungian labels;
- neuroscience becomes pseudo-explanation;
- same A/B/C structure becomes visible to the player;
- randomizer output starts sounding machine-generated.

Correction:
reduce weight, choose NONE, return to normality, or REROLL.
