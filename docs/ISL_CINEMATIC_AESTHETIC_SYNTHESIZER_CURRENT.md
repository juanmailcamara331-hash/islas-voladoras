## CINEMATIC BRACKET TEST
For important scenes create at most 3 variants:
A · MOODY: darker / stronger shadow mass.
B · BALANCED: intermediate tonal field.
C · READABLE: brighter / softer shadow pressure.

LOCK composition, camera, world content and primary color relationships.
Perturb only 1–2 variables per comparison, usually exposure/shadow mass or warmth/coolness.
Human chooses by function, not recency.

## READABILITY GATE
Ask:
- Can I read the next useful action / threat / route?
- Are faces/hands/crew readable when they matter?
- Are black areas shaped rather than crushed?
- Are highlights preserving material shape rather than clipping?
- Does atmosphere create depth instead of milkiness?
- Is the focal hierarchy obvious without HUD?
- Does the scene still feel inhabited?
- Does the image remain legible on a normal mobile/tablet display?

Fail if cinematic mood hides necessary interaction or if readability flattens the emotional image.

## COLOR / BLACKS / SHADOWS
Treat black level as narrative and spatial material, not a global slider.
Prefer:
- deep local blacks;
- readable near-black texture;
- shadow color informed by environment;
- warm/cool relational contrast rather than blanket orange/teal;
- saturation hierarchy, not uniform saturation;
- highlight control to keep cloud, skin, metal and sail detail.

Avoid:
- lifted-grey everything;
- crushed-black everything;
- global LUT dependence as SOURCE_OF_TRUTH;
- generic blockbuster palette;
- excessive bloom/fog used to fake production value.

## GAME / FILM CROSS
Film contributes:
- lighting motivation;
- contrast hierarchy;
- lens/focal grammar;
- blocking;
- temporal reveal;
- color continuity;
- negative space;
- emotional exposure.

Games add:
- persistent readability;
- interactive affordance;
- variable camera/device;
- player-controlled pacing;
- accessibility;
- target hardware;
- UI coexistence;
- repeat exposure.

Therefore:
CINEMA FUNCTION → INTERACTIVE MUTATION → DEVICE TEST → HUMAN READ.
