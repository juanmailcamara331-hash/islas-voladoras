## IDEA CENTRAL
ISL puede romper leyes universales, pero nunca de forma arbitraria.

Una ley imposible debe:
1. ser legible;
2. tener una regla local consistente;
3. producir una contradicción observable;
4. cambiar cómo se juega / vive / interpreta el lugar;
5. aterrizar en una consecuencia humana.

No basta con “mundo raro”.

## PRISM-EYE BRIDGE
El ojo-prisma puede ser un dispositivo diegético para acceder a mundos o estados donde una ley física se refracta en otra.

WHITE CRYSTAL EYE
→ SPECTRAL REFRACTION
→ PHYSICAL CONTRADICTION
→ OTHER WORLD / OTHER STATE
→ HUMAN CONSEQUENCE
→ RETURN WITH NEW READING.

No es un menú de multiverso.
No es teletransporte arbitrario.
Cada refracción necesita causa, lectura y consecuencia.

## REFERENCE-BY-FUNCTION
Referencia funcional posible: ficción especulativa cómica donde el absurdo obedece reglas internas y las ideas cósmicas tienen consecuencias cotidianas.

Extraer:
- coherencia interna del absurdo;
- humor nacido de la lógica del sistema;
- contraste entre escala cósmica y vida corriente;
- reglas que parecen chiste pero terminan afectando economía, relaciones, oficio, peligro o rutina.

No copiar:
- personajes;
- mundos;
- voz literaria;
- chistes;
- iconografía;
- estructuras reconocibles de obras existentes.

## REGLA DE DISEÑO
Cada ley imposible debe poder resumirse en una frase que un jugador entienda por observación.

Ejemplos de familias:
- la gravedad se inclina hacia seres vivos;
- el sonido tiene peso;
- las sombras llegan antes que sus objetos;
- la distancia cambia con la memoria;
- el color modifica propiedades materiales;
- el viento conserva o borra rutas;
- ciertas superficies viven tiempos distintos.

## TEST MINIMO
Para cualquier ley candidata:
- ¿puede entenderse sin texto largo?
- ¿genera al menos 2 interacciones distintas?
- ¿produce una consecuencia no puramente visual?
- ¿puede fallar o incomodar?
- ¿afecta a alguien, no sólo al decorado?
- ¿mantiene una salida / descanso / vuelta a lo humano?

Si sólo produce espectáculo: COLOR.
Si produce interacción pero no consecuencia: PROTOTYPE.
Si produce sistema + consecuencia humana + memoria: candidato fuerte, aún NO CANON hasta CQC + humano.
