# ISL · CROSS-ART CRAFT & PRACTICE LAYER · CURRENT
Fecha: 2026-09-22
Estado: ACTIVE · TRANSVERSAL · ISL ONLY

## PROPÓSITO
Evitar que ISL piense sólo como videojuego, sólo como software o sólo como IA.
Cada problema puede beneficiarse de principios probados en otras artes, oficios y disciplinas.

## REGLA MADRE
NO COPIAR ESTILOS.
EXTRAER PRINCIPIOS DE OFICIO → CONTRASTAR → MUTAR → PROBAR EN ISL.

## FAMILIAS DE OFICIO
- cine: blocking, montaje, suspense, continuidad, mise-en-scène;
- arquitectura: recorrido, escala, umbral, luz, material, orientación;
- música: tensión/reposo, leitmotiv, textura, silencio, polirritmia;
- teatro: presencia, entrada/salida, atención, espacio compartido;
- pintura/ilustración: composición, valor, jerarquía, borde, vacío;
- escultura: silueta, peso, tactilidad, lectura 360º;
- diseño gráfico: legibilidad, contraste, ritmo, sistema;
- UX/HCI: affordance, feedback, error recovery, carga cognitiva;
- literatura: voz, omisión, subtexto, ritmo, motivo;
- cómic: secuenciación, panel, pausa, fuera de campo;
- fotografía: encuadre, profundidad, exposición, momento;
- artesanía: tolerancia, material, huella de mano, reparación;
- danza: timing, peso, anticipación, espacio corporal;
- magia/ilusionismo: expectativa, misdirection ética, reveal;
- museografía: recorrido, interpretación, capas de información;
- restauración/conservación: reversibilidad, provenance, no destruir original;
- ingeniería: tolerancias, redundancia, failure modes, observabilidad;
- investigación científica: hipótesis, falsabilidad, experimento mínimo, réplica;
- antropología/ritual: significado social, repetición, memoria, pertenencia;
- neurociencia/percepción: atención, saliencia, memoria, fatiga, predicción;
- marketing/editorial: promesa, framing, distribución, recuerdo;
- derecho/IP: cadena de titularidad, evidencia, licencia, riesgo proporcional.

## PATRÓN DE USO
1. problema real;
2. elegir 1–3 oficios relevantes;
3. extraer principio;
4. buscar contradicción;
5. traducir a una decisión ISL;
6. prototipo mínimo;
7. evidencia humana;
8. archivar aprendizaje;
9. reutilizar sólo si funcionó.

## EJEMPLOS
- nivel confuso → arquitectura + UX + fotografía;
- criatura memorable → escultura + danza + sonido;
- boss reveal → cine + magia + música;
- objeto físico → artesanía + escultura + derecho;
- onboarding → UX + cómic + museografía;
- ciudad → arquitectura + antropología + teatro;
- making-of → documental + editorial + archivo;
- marketing → narrativa + SEO + diseño gráfico;
- sistema de decisiones → ciencia + derecho + ingeniería.

## BEST-PRACTICE FILTER
Una referencia sólo entra si aporta una función comprobable.
Preguntas:
- ¿qué problema resuelve?
- ¿qué coste introduce?
- ¿qué rompe si se copia sin contexto?
- ¿qué parte puede mutarse sin perder ISL?
- ¿qué evidencia mínima validaría el cruce?

## REGLA DE RAREZA
Para outputs creativos importantes:
- al menos una disciplina cercana;
- opcionalmente una disciplina lejana;
- una tensión entre ambas;
- no más referencias de las que podamos explicar funcionalmente.

## ANTI-COLLAGE
No concatenar referencias por prestigio.
No "X + Y + Z" como sustituto de una idea.
La mezcla sólo existe si produce una regla nueva, una decisión nueva o una experiencia nueva.

## HUMAN CRAFT PASS
Buscar:
- decisiones visibles;
- ritmo no uniforme;
- materialidad;
- límites aceptados;
- pequeños accidentes útiles;
- edición;
- descarte;
- reparación;
- silencios.

## CONNECTION WITH RANDOMIZER
El Human Variation Randomizer puede seleccionar:
- 1 disciplina cercana;
- 0–1 disciplina lejana;
- número de calas;
- medio;
- destino;
- tensión.

Pero SOURCE_OF_TRUTH y función siempre ganan al azar.

## CONNECTION WITH AUTOMATIONS
Buenos días / buenas noches:
usar esta capa libremente para regalos multicapa.

Inconsciente / PC-30 / auditorías:
usar sólo cuando una disciplina externa pueda mejorar una decisión real.

## STOP RULE
Si el cruce suena inteligente pero no cambia una decisión o experiencia, no sirve.


## LIVE CULTURE / CITY PERFORMANCE · 2026-09-22
Para ciudades/islas, cruzar cuando proceda:
- teatro → blocking, presencia, atención compartida;
- concierto → dinámica, espera, clímax, silencio, audiencia;
- festival → ciudad temporal, recorrido, múltiples focos, ritual;
- museografía → observar sin obligación, capas de lectura;
- antropología → función social, memoria, pertenencia;
- arquitectura → plazas, graderíos, backstage, umbrales;
- ingeniería → montaje/desmontaje, seguridad, fallos;
- historia cultural → contexto, contradicción, huella.
