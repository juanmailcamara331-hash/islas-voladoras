# ISL · GUIDED WORLD / HUD / PLAYFLOW DIRECTION · CURRENT
Fecha: 2026-09-23
Estado: HUMAN AUTHOR LOCK · CANON DIRECTION · TRANSVERSAL · ADDITIVE · ISL ONLY

## PURPOSE
Seal the current playflow direction so world, HUD, combat, progression, islands, replay and visual bullets inherit it without the human needing to repeat it.

This does NOT replace PRIMARY, SAFE HARBOR, existing world systems, Huellas, replay hypotheses or combat research.
It constrains how they should feel and guide the player.

## 1. HUD INVARIANT
HUD should remain MINIMAL by default.

Functional reference:
Skies-of-Arcadia-like restraint and clarity, not surface imitation.

Prefer:
- diegetic information;
- world cues;
- concise turn/combat information only when needed;
- temporary contextual prompts;
- readable silhouettes and staging;
- information that disappears when understood.

Avoid by default:
- persistent mission tracker;
- giant objective arrows;
- permanent minimap;
- checklist clutter;
- excessive status bars;
- UI replacing spatial understanding.

HUD can become denser temporarily in combat or accessibility modes when function requires it, but must return to restraint.

## 2. NAVIGATION INVARIANT
The world should guide the player through:
composition;
landmarks;
light;
wind;
sound;
architecture;
NPC flow;
skyline;
terrain;
movement of creatures;
environmental rhythm;
visible consequences.

Primary objective should often be inferable from the place itself.

No mandatory mission marker or map dependency by default.

Test:
Can a human understand “roughly where I should go next” without a glowing arrow?

## 3. WORLD STRUCTURE
ISL is NOT a conventional unrestricted open world.

Direction:
GUIDED · SEMI-OPEN · LOCAL FREEDOM · DEEP · INTUITIVE.

The player can:
- wander within meaningful local spaces;
- find secrets;
- meet people;
- discover side routes;
- linger;
- return later;
- experience different internal histories by archetype / Huella / replay state.

But macro-rumbo remains authored and legible.

Preferred structure:
authored zones / islands / districts connected by traversal and progression gates.

## 4. DIEGETIC GATES
Separate or delay areas through world logic rather than menu locks whenever possible.

Candidate families:
- curtains/walls of air;
- unstable winds;
- pressure fronts;
- impossible gravity seams;
- sleeping creatures;
- social permission;
- ship capability;
- relic resonance;
- route knowledge;
- crew trust;
- Huella state;
- completed local contradiction;
- replay-layer changes.

The gate should communicate:
“I cannot meaningfully pass yet”
rather than:
“the game designer put an invisible wall here.”

## 5. RUMBO WITHOUT HAND-HOLDING
Design target:
the player should feel free, not lost;
guided, not dragged;
curious, not managed.

World guidance ladder:
1. composition;
2. motion/light/audio;
3. NPC/environmental cue;
4. subtle contextual prompt;
5. explicit UI only if comprehension still fails.

Never jump directly to markers if the world can teach the route.

## 6. ARCHETYPE / REPLAY VARIATION
Macro structure may remain guided while local experience changes through:
- emergent archetype;
- starting seed/lens if later validated;
- crew composition;
- Huellas;
- relationships;
- equipment;
- replay layer;
- discovered secrets.

The same zone can therefore have different:
- routes;
- affordances;
- NPC reactions;
- hidden rooms;
- equipment access;
- interpretation;
- danger;
- memory.

Guided does NOT mean identical.

→ SHARED COMBAT BEHAVIOURS
→ ABILITY MUTATION
→ ISLAND EQUIPMENT

## 8. VISUAL / TONAL FIELD
Human author direction:
ISL should remain:
- deep but accessible;
- creative;
- slightly dark;
- sensual / erotic in an adult, tasteful, contextual way;
- punk;
- irreverent;
- tender;
- funny;
- philosophical;
- strange;
- capable of high-concept escalation.

Functional reference family only:
- Skies of Arcadia → readable adventure, ship scale, restrained HUD, turn-based spectacle;
- Rick-and-Morty-like function → high-concept rule-breaking + irreverent consequence, never surface copying;
- Recess / La Banda del Patio → legible micro-societies, groups, social rules, friendship;
- Tim-Burton-like function → outsider sympathy, dark/tender contrast, silhouette/emotional strangeness;
- Jung → dynamic archetypal tensions/attractors, not diagnoses or fixed personality classes;
- Terry-Pratchett-like function → humour that exposes systems, institutions and ordinary human contradiction, never prose imitation.

Guard:
sensual/erotic material applies only to clearly adult characters/contexts.
Never sexualize childlike characters or child-coded social references.

## 9. REFERENCE DISTANCE
References are engines, not surfaces.

Use:
REFERENCE → FUNCTION → CONTRAST → ISL MUTATION → TEST.

Do not copy:
characters;
costumes;
 branded iconography;
 recognizable compositions;
 dialogue;
 jokes;
 signature props;
 franchise visual language.

## 10. CREATION CHECK
Whenever creating or reviewing:
- island;
- dungeon;
- hub;
- combat;
- ship scene;
- route;
- HUD;
- UI;
- replay variation;
- progression gate;
- visual bullet;

ask silently:

1. Is HUD doing work the WORLD could do?
2. Does the space pull the eye/body toward useful possibilities?
3. Can the player wander meaningfully without becoming directionless?
4. Is the gate diegetic and legible?
5. Does local variation preserve macro-rumbo?
6. Does this feel lived/human, not theme-parked?
7. Does weirdness have consequence?
8. Is the tone still ISL rather than reference collage?
9. Is any new complexity earning its place?
10. Can we remove one UI/system element and keep the experience?

## 11. QUALITY TARGET
ISL should feel like:
a magistrally guided adventure that gives the player enough freedom to believe the journey is theirs.

Not:
a corridor.

Not:
a checklist open world.

Not:
a HUD-driven GPS game.

## 13. PERCEPTUAL ACTION GRAMMAR 01 · CANDIDATE
Estado: PROVISIONAL STRONG PATTERN · EVIDENCE PENDING · NO GLOBAL PROPAGATION · NO CANON

Purpose:
make compact action controls learnable through a stable perceptual grammar without replacing text, icons, accessibility or human testing.

Core grammar:
MOTHER SHAPE
+ SEMANTIC MICRO-DEFORMATION
+ STABLE POSITION
+ SIMPLE ICON
+ SEMANTIC MICRO-ANIMATION
+ TEXT BACKUP
+ HUMAN MATERIAL TRACE.

Principle:
GRAMMAR STABLE + MATERIAL HISTORY IMPERFECT.

Diegetic rule:
the HUD should not feel like an abstract interface designed outside the world.
It should feel like equipment the crew uses, repairs and understands, while remaining excellent for the player.

Current skyship candidate:
- keep controls small and restrained;
- one shared compact irregular technological family;
- avoid rectangular cards / fantasy plaques / five unrelated silhouettes;
- action identity may differ through small shape cues, orientation, contour or particle behaviour;
- MANIOBRA: lateral curvature / directional drift;
- DISPARAR: compression / release;
- DEFENDER: enclosing contour / absorb;
- REPARAR: seam / fragments rejoin;
- TRIPULACIÓN: clustered nodes / convergence.

Learning guard:
position stays stable between contexts.
Do not randomize action placement.

Accessibility guard:
shape + icon + text must coexist during validation.
Color, animation or particles must never be the only cue.

Evidence boundary:
perception / affordance research may INFORM candidate mappings.
Do not claim universal neurological shapes or automatic intuition.
ISL mapping remains hypothesis until prototype + ablation + human evidence.

Cheap falsification:
FULL = shape + icon + stable position + semantic animation + text.
ABLATION A = remove text.
ABLATION B = equalize shapes.
ABLATION C = neutralize icons.
ABLATION D = remove motion.
Compare recognition, hesitation, error and learning over exposure.

Fail / mutate if:
- controls become larger or louder than the world;
- they read as generic app buttons, medieval/fantasy plaques or generic alien tech;
- five controls stop reading as one family;
- particles distract from combat;
- color becomes mandatory;
- the mapping needs explanation rather than becoming learnable;
- the HUD carries more personality than ship / crew / world;
- accessibility degrades.
