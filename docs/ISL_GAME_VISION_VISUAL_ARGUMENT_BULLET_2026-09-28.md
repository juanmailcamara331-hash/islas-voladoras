## REFERENCIAS EXTERNAS · SÓLO FUNCIÓN

### TIM BURTON / MOMA
Funciones extraídas:
- presentar una obra por DOS LECTURAS simultáneas: recorrido narrativo + motivos recurrentes;
- permitir que alguien siga la historia o simplemente saboree atracciones visuales;
- convertir la entrada en umbral de mundo;
- sombras/reflejos/material gráfico como experiencia 360°, no marco decorativo;
- personaje reconocible por quirk/silueta/ritmo antes que explicación.

Mutación ISL:
ARGUMENTO PRINCIPAL + CAPAS/MOTIVOS, no museo Burton.
PUERTA DE VISIÓN = umbral ISL original.
Tipografía/forma propia; no imitar lettering, siluetas ni criaturas protegidas.

### TERRY PRATCHETT / DISCWORLD + PAUL KIDBY
Funciones extraídas:
- personajes larger-than-life definidos por contradicciones y relaciones;
- mundo presentado junto a sus personas, flora, fauna, objetos, rutas y economía;
- ilustración como extensión de descripción, no como sustituto de carácter;
- ensemble: la química entre figuras cuenta tanto como el retrato individual;
- detalle lateral que recompensa mirar sin bloquear la lectura principal.

Mutación ISL:
PERSONAJE = SILUETA + CONTRADICCIÓN + VERBO + RELACIÓN + HUELLA.
MUNDO = PERSONAS + OFICIOS + RUTAS + OBJETOS + CONSECUENCIAS.
Humor lateral; no copiar nombres, diseños, chistes, prosa ni iconografía Discworld.

### SPIELBERG / AMBLIN / DGA
Funciones extraídas:
- reducir distancia estética: meter al público dentro de la experiencia;
- emoción humana como centro del espectáculo;
- wonder + fear + humor + mystery pueden coexistir;
- epifanías relacionales pequeñas pueden sostener una escala enorme;
- mapa de historia/set-pieces para planificar sin ahogar espontaneidad;
- el espectáculo funciona mejor cuando deriva de una relación/objetivo humano.

Mutación ISL:
HUMAN ANCHOR → WONDER → PRESSURE → REVEAL → HUMAN RETURN.
Cada gran imagen necesita una pregunta humana.
Cada monstruo/landmark necesita escala + relación + consecuencia.
No imitar planos, escenas, blocking o composiciones reconocibles.
