# ISL — VIS-00 / DD-VIS-01 · VISUAL CAMPAIGN LAB v0.23
Fecha: 2026-09-18
Estado: ACTIVO / NO CANON AUTOMÁTICO

## OBJETIVO
Usar Midjourney + Discord + humanos como laboratorio visual controlado.
No buscar "la imagen más bonita"; buscar:
- identidad ISL;
- puertas de entrada distintas;
- segmentos de audiencia;
- señales comparables;
- material reutilizable para campañas sin congelar el juego.

## FAMILIAS INICIALES
A · HYPERREAL WONDER
Cielo inmenso, materiales realistas, nave-hogar, escala física, luz atmosférica.
Función: alcance amplio / thumbnails / música / poster.

B · POETIC AUTHORIAL
Pictórico, artesanal, extraño, más íntimo, textura y símbolos propios.
Función: identidad / prensa / biblia visual / comunidad profunda.

C · DARK SEPARATION
Mecánica imposible, belleza torcida, vulnerabilidad, espacios que fallan.
Función: adulto / misterio / campaña de tensión.

D · WARM CREW / HOME
Pandilla, cocina, taller, objetos, rutina, humor y cariño no sentimental.
Función: vínculo / comunidad / cápsulas / Discord.

E · GOTHIC MECHANISM
Arquitectura torcida, máquinas con reglas, cuento oscuro, ruina bella.
Función: regiones oscuras / dungeons / teaser adulto.

F · 90s SKY GANG
Energía juvenil, aventura, diseño gráfico atrevido, irreverencia.
Función: clips cortos / social / comunidad.

## PROTOCOLO DE GENERACIÓN
1. misma escena base;
2. una sola variable visual cambia por variante;
3. conservar composición/semántica cuando se compare estilo;
4. registrar prompt, seed si existe, modelo/versión, fecha, autor humano;
5. no mezclar resultados de campañas distintas en una misma encuesta.

## MIDJOURNEY
Discord bot = herramienta de exploración.
NO es autoridad estética.
Toda pieza debe guardar:
- prompt;
- variación;
- upscaler/model version;
- derechos/licencia aplicable;
- función de campaña.

## CQC VISUAL
0–5:
- identidad ISL;
- fuerza thumbnail;
- narrativa;
- emoción;
- memorabilidad;
- legibilidad;
- materialidad;
- coherencia con producto real;
- reusabilidad;
- riesgo de expectativa falsa.

## TEST DE POBLACIÓN
No hablar de "ganador universal".
Segmentar por:
- audiencia fría;
- gente que ya conoce ISL;
- jugadores aventura/JRPG;
- gente atraída por dark fantasy;
- música/relax;
- amigos/Discord (muestra cualitativa, no representativa).

Métricas:
- primera elección;
- click/expand;
- guardado;
- tiempo;
- comentario espontáneo;
- "quiero saber más";
- concordancia con juego real.

## CAMPAÑA EVOLUTIVA
Cada familia puede tener 3 fases:
HOOK → CONTEXTO → PROFUNDIDAD

Ejemplo:
imagen hiperrealista aérea
→ cápsula de lore
→ música / escena / wishlist futura.

## ANTI-SESGO
- amigos ≠ mercado;
- likes ≠ intención;
- imagen espectacular ≠ identidad;
- más población ≠ mejor señal si la audiencia no es relevante;
- no elegir CANON por CTR.

## ESTADO DE LAS COVERS ANTERIORES
Las covers generadas previamente pasan a:
PLACEHOLDER / PROTOTYPE ONLY.
No representan calidad visual final ISL.

## PRIMER EXPERIMENTO
Escena común:
"Nave-hogar suspendida sobre costa dormida al amanecer."

Generar 4 familias A–D, 4 variantes por familia.
Total: 16.
Luego:
- CQC interno;
- top 2 por familia;
- Discord microtest;
- sólo entonces test público si merece.
