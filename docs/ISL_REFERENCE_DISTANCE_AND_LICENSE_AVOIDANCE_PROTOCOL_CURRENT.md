# ISL · REFERENCE DISTANCE / EVOCATION / LICENSE AVOIDANCE PROTOCOL · CURRENT
Fecha: 2026-09-22
Estado: ACTIVE · TRANSVERSAL · ISL ONLY
Naturaleza: creative + rights-risk protocol; no sustituye revisión jurídica.

## PROPÓSITO
Permitir que referencias históricas, secundarias, culturales o musicales aporten olor, función, energía y memoria sin convertir ISL en copia, soundalike demasiado cercano o dependencia de licencias.

## PRINCIPIO
REFERENCIA ≠ MATERIAL.
INSPIRACIÓN ≠ REPRODUCCIÓN.
EVOCAR FUNCIÓN, NO RECONSTRUIR LA FIRMA.

## CLASES DE REFERENCIA
A. HISTÓRICA / DOMINIO PÚBLICO POTENCIAL
- arquitectura;
- pintura antigua;
- ritual;
- folklore;
- técnica;
- forma social;
- textos/obras cuando derechos estén realmente expirados.
Regla: comprobar país/obra/edición/grabación; una obra antigua puede tener una grabación/arreglo/foto moderna protegida.

B. CONTEMPORÁNEA / PROTEGIDA
Se usa sólo como referencia funcional:
- tensión;
- textura;
- densidad;
- tempo;
- relación de masas;
- tipo de humor;
- estructura de reveal;
- energía;
- contraste;
- tratamiento material.

C. SEGUNDONA / LATERAL
Referencia no central que aporta una función pequeña.
Debe tener peso bajo y no dominar la identidad final.

## DISTANCE TEST
Antes de producir:
1. ¿puedo describir el objetivo sin nombrar la referencia?
2. ¿hemos extraído 2–5 funciones abstractas?
3. ¿hemos cambiado medio, estructura, contexto o combinación suficiente?
4. ¿el resultado sigue teniendo valor si el público no reconoce la referencia?
5. ¿una persona razonable podría confundirlo con una obra/tema/personaje concreto?
6. ¿hemos conservado algún elemento demasiado identificable?

Si 5 o 6 = sí → REDISEÑAR / ALEJAR.

## MÚSICA · "OLER A" SIN LICENCIAR
Permitido como brief:
- tempo aproximado;
- métrica;
- instrumentación amplia;
- densidad;
- rango dinámico;
- tipo de groove;
- grado de disonancia;
- sensación espacial;
- estructura general;
- energía emocional;
- era/género amplio;
- técnicas de producción genéricas.

Evitar:
- melodía reconocible;
- progresión + ritmo + contour usados juntos de forma demasiado identificable;
- hook;
- letra/frase;
- riff;
- línea de bajo distintiva;
- sample;
- stem;
- recreación de voz/timbre de artista;
- arreglo demasiado paralelo;
- "haz una copia de X pero cambia dos notas".

Prompt preferido:
"Original score with [functional traits]. Do not quote, interpolate, sample or recreate any identifiable melody, lyric, riff, hook, vocal identity or arrangement from existing works."
