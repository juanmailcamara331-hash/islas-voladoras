## 9. Why there is no full binary duplicate

Do **not** clone every image, GLB, audio, APK and historical file into a second tree by default.

That would create:
- duplicate sources-of-truth;
- storage noise;
- ambiguity about masters;
- new rollback risk.

Binary/media safety continues through:
existing Drive storage + Git history + registries + provenance + backup protocols.

If a future experimental step will destructively replace a specific binary/master, make a dedicated immutable copy **before that step** and register it here.
